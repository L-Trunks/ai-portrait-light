# 对照实验：十五轮是怎么打出来的

这份是过程记录。**结论都已经收进 [SKILL.md](../skills/zimage-portrait-light/SKILL.md)，这里回答的是「凭什么这么说」。**

方法很笨：每轮固定其他一切，只改一句话，同种子出 5~6 张，肉眼看 + 量八个数。
一共 ~120 张。下面按轮列，只留改变了结论的那些。

---

## 噪声底：先量摆幅，再谈效果

⛔ 第一件事不是做实验，是量噪声。**同一条提示词、同一个 seed、在同一套 ComfyUI 上重抽 5 次，
平均像素差 29/255** —— z-image 在这里不可复现。

所以任何改法的效果**必须大过这个摆幅才算数**。没有这一步，前面几轮的「好像变了一点」全是自欺。

---

## r1 · 堆形容词：五张几乎一模一样

五档强度的光线形容词（「柔和的逆光」→「强烈的丁达尔光柱」），全部堆在句尾。

结果：P1 6→7、HALO 1.43→1.42、dB 全是 −7~−9。**三项纹丝不动**，只有发梢挤出一点点轮廓光。

两个病灶：① 锚在末尾被前面 400 字描述稀释；② 场景句写的是「身后是干净的暖白色墙面」——
**物理上不可能逆光**，场景赢了光线。

## r2 · 决定性的一轮：改场景赢，挪位置没用

拆成两组单变量：

- M1/M2 只挪光线句的位置（尾 → 首 → 前后各一份）：**P1 / dB / HALO 全部不动**。
- M3/M4/M5 只把场景换成「身后是敞开的店门和门外明亮的街道」：**P1 7→12、CLIP 0.2%→3.8%**，逆光一次就出来了。

⭐ 推论：**光不是靠形容词写出来的，是靠把场景写成物理上只能这么打光。**
这是全部一百多张里最值钱的一条。

## r3 · 空气介质，以及「冷暗部」的反效果

三条单变量各自归因：

| 改动 | dB | 判定 |
|---|---|---|
| 只写「金色时刻」 | **−10.11** | 等于没有 |
| + 「空气里浮着被照亮的细小尘埃」 | **+1.37** | ⭐ 介质是把 dB 拉回正的那一手 |
| + 「暗部是偏冷的青灰色」 | b\* 掉到 −1.04 | ⛔ 反效果，模型把**整张图**一起吹冷了 |

⛔ 模型不会只冷暗部。暖冷分离只能靠**场景自带**（见 r4）。

## r4 · 场景排位：树林赢在自带暖冷分离

五个场景同配方对照，树林 dB **7.15**（参考片 8.44）最接近 —— 因为它天然有「暖光柱 + 冷绿树荫」，
不用另写那句反效果的冷暗部。河堤次之（HALO 1.64 最高，逆光草叶边缘全透）。

⛔ 但五张的人**还是被平光照着**。光是背景装饰，没落在她身上 —— 这条病一直拖到 r13 才解决。

## r6 · 柔焦提示词：零效果，必须放后期

参考片被形容成「轻微柔焦」，实测 LAP 参考 19、我们 200~275，锐了一个量级。
本轮五档柔焦写法单变量：

结果 **LAP 275→318（反而更锐）**，肉眼五张无差。

⛔ 柔焦这类**光学后处理**写进提示词完全无效，只能靠后期 bloom。
⚠️ 唯一有效的提示词侧软化是**加雾**（晨雾把 LAP 96 压到 55）——因为雾是场景里真实存在的东西。

## r7~r10 · 把光搬进近景，以及字数预算

光的配方对上参考片之后（P1 17 对 15.5、dB 8.64 对 8.44），并排一看，剩下的差全在**景别**。

⛔ 近景档必须**整条重写**，套原来的模板会被身形句和下装句把景别顶回全身。
这一条后来独立成了通用规律：**画框外的身体部位一个字都不能写**。

## r11~r13 · 推翻自己：不是「透光」，是构图

用三张外部参考照反推，发现和 r1~r10 的根本分歧：**光源本体不进画面**，
镜头前有遮挡物虚化成一片，光是被挡住之后漏进来的一部分，而不是整片逆光。

r12 单变量=相机句（满框 → 偏侧 → 侧脸）：

| | LAP | BGFG |
|---|---|---|
| 正脸满框 | 96 | 0.48 |
| 侧脸偏一侧 | **24.5** | **3.36** |
| 参考片 | 16.6 | 3.99 |

⭐ **构图比光更强。** 同一套光，只把人挪到画面一侧、只给侧脸，两个数一次对上参考片。

r13 固定「侧脸 + 耳后穿发 + 流动虚化背景」三件套，换 6 个场景验证泛化：**6/6 全成立**，
含非绿背景（樱花粉）和人造光（夜街，dB 27.1）。

⛔ 同时推翻了自己前一轮的验收线：CLIP=0 不是目标。入选的两张 CLIP 0.67/1.77，
被否的那张才 0.13、LAP 24.5 全场最好 —— **数值最漂亮的观感最差。**

## r14 · 扩展：正脸 / 半身 / 神态 / 多人

四组单变量，把只在「侧脸近景」验过的配方往外推：

- **正脸**：⭐ 推翻 r12 的「正脸会把光锁死成硬边缘光」。换光的写法即可，斜后光和环光**各 6/6**。
- **神态**：⭐ 笑能开到大笑露牙，**4/4**，不崩脸也不顶掉光。⚠️ 只在不挂 LoRA 时成立。
- **多人**：⭐ **4/4 人数全准**。⛔ 两处必须一起改（尾句人数 + 场景句主语），漏一处塌回一个人。
- **景别**：⛔ **半身 0/2** —— 相机句喊「从腰往上入镜」没用。
  景别是靠**画框内的身体/服装内容**撑出来的，不是靠相机句喊出来的。

## r15 · 冷雾档：四样叠加才成立

参考照里有一条**方向完全相反**的光路：正脸大特写、背景是一整面冷蓝纱帘、
背景比脸亮、b\* = −13.5（负的）、主光是她手里那朵被照透的花。

r14 已经把构图、冷调、纱帘、手捧花全部还原对了，差三样：花只是被照亮没在发光、雾太薄、整张比参考亮一档。
本轮做累加梯子：

**自发光 + 厚雾 + 压暗 + 柔，四样全叠加**才同时对上三项（P1 15 / STD 57.0 / b\* −12.1）。
单独去掉任何一样都掉。⛔ 改暖调直接废，去掉花直接废。

## 全身档：另外 36 张

近景档的规律**不能直接套到全身**：近景靠背景整个化成光斑，全身背景是实景，只能靠场景几何。

| | P1 | dB | b\* |
|---|---|---|---|
| 改造前 20 张 | 11.5 | 2.55 | 2.48 |
| 光感配方 36 张 | 20.0 | 1.92 | **8.73** |
| 参考片 | 15.5 | 8.44 | 13.19 |

两个坑：

- ⛔ **身后不能有一整面墙 / 一扇门 / 一排橱窗** —— 36 张里 10 张栽在这上面，
  墙把太阳挡在画框外，模型改从正面补光，全退化成平光。
  修法：站到**巷口 / 门洞 / 两根柱子之间的缺口正中**，10 张修好 8 张。
  剩下 2 张「场景全部内容就是一整面平面」的**直接换地点**，别硬凑。
- ⚠️ **太阳只挂在远处地平线上不算数**：数值最漂亮的那组（P1 15、b\* 15.1，全场最接近参考片）
  **人身上一点光都没有**，就是个好看的背景板。

## 出这十张成品时又踩的两条

- ⛔ **光源离主体远 = 零轮廓光。**「夜晚天台的边缘，整片城市霓虹就在她身后」——
  霓虹在几百米外，人身上零轮廓光。同一条也砸过「太阳卡在她身后两棵树的树干之间」。
  ⭐ 判据换成**光源离她有多近**：齐腰的花枝之间 / 身后与肩同高的火盆 / 架在身后与头同高的射灯。
- ⛔ **景别没守住时，画框外的字段会被模型自己编出来。** 半身档按规矩不写下装，
  前提是画框真的切在腰上；一旦画框滑到膝盖，下半身进了画面而提示词里一个字都没有，模型就自由发挥。
  ⭐ 修法不是加字数，是**换景别**（改走中景，中景本来就要写下装），再用肯定句写死。

⭐ 还有一条方法上的：**挑片比改措辞收敛快。**
十张成品是 30 张候选（每个位置 3 个种子）里挑出来的，10 个位置**全部**换掉了默认那张。
同提示词换种子的摆幅，比绝大多数措辞改动都大。

## 度量脚本

八个数的口径。⛔ 先读 SKILL.md 第 4 节的「五条别当及格线」再用，
**数值全对也可能是废片，唯一可靠的验收是肉眼看发丝有没有一根根亮起来。**

```python
# -*- coding: utf-8 -*-
"""量一张图的「光感」指标，用来把参考片的感觉变成可比的数。
  P1     最暗 1% 的亮度。胶片/柔焦片黑不下去，越高越"奶"
  CLIP%  >250 的像素占比。逆光片必然有一片过曝
  STD    全图亮度标准差
  ΔB     高光区 b* 减 暗部区 b*。正=亮处暖暗处冷（黄金时刻的标志）
  b*     全图 b* 均值，正=偏黄
  HALO   高光周围 12px 环带的平均亮度 / 全图均值。柔焦会把光晕开
  LAP    中央 40% 区域的拉普拉斯方差（对焦是否实）
  BG/FG  边缘区 lapvar / 中央区 lapvar。越小背景越化
"""
import glob, os, sys
import numpy as np, cv2

sys.stdout.reconfigure(encoding="utf-8")


def imread(p):
    return cv2.imdecode(np.fromfile(p, dtype=np.uint8), cv2.IMREAD_COLOR)


def 量(p):
    im = imread(p)
    if im is None:
        return None
    h, w = im.shape[:2]
    if max(h, w) > 1400:
        s = 1400 / max(h, w)
        im = cv2.resize(im, (int(w * s), int(h * s)), interpolation=cv2.INTER_AREA)
        h, w = im.shape[:2]
    lab = cv2.cvtColor(im, cv2.COLOR_BGR2LAB)
    L = lab[:, :, 0].astype(np.float32)
    B = lab[:, :, 2].astype(np.float32) - 128.0
    g = cv2.cvtColor(im, cv2.COLOR_BGR2GRAY)

    p1 = float(np.percentile(L, 1))
    clip = float((L > 250).mean() * 100)
    std = float(L.std())
    hi, lo = L > np.percentile(L, 85), L < np.percentile(L, 25)
    dB = float(B[hi].mean() - B[lo].mean())
    bm = float(B.mean())

    # 柔光晕：高光核心向外膨胀 12px 的环带，看它比全图亮多少
    core = (L > 235).astype(np.uint8)
    if core.sum() > 50:
        ring = cv2.dilate(core, np.ones((25, 25), np.uint8)) - core
        halo = float(L[ring > 0].mean() / max(L.mean(), 1e-6))
    else:
        halo = 0.0        # ⛔ 光源出画时必为 0，别读成「没有光晕」

    y0, y1, x0, x1 = int(h * .3), int(h * .7), int(w * .3), int(w * .7)
    cen = float(cv2.Laplacian(g[y0:y1, x0:x1], cv2.CV_64F).var())
    m = np.ones((h, w), bool); m[y0:y1, x0:x1] = False
    gl = cv2.Laplacian(g, cv2.CV_64F)
    edge = float((gl[m] ** 2).mean())
    return dict(P1=p1, CLIP=clip, STD=std, dB=dB, b=bm, HALO=halo,
                LAP=cen, BGFG=edge / max(cen, 1e-6))


def 跑(名, 文件, 详细=False):
    rows = [(os.path.basename(f), 量(f)) for f in 文件]
    rows = [(n, r) for n, r in rows if r]
    if not rows:
        print("%-22s 没图" % 名)
        return
    ks = ["P1", "CLIP", "STD", "dB", "b", "HALO", "LAP", "BGFG"]
    if 详细:
        for n, r in rows:
            print("  %-30s %s" % (n[:30], "  ".join(("%7.2f" % r[k]) for k in ks)))
    med = {k: float(np.median([r[k] for _, r in rows])) for k in ks}
    print("%-22s n=%-3d %s" % (名, len(rows), "  ".join(("%7.2f" % med[k]) for k in ks)))
    return med


if __name__ == "__main__":
    # 用法：python 光感度量.py 参考=ref/*.png 我的=out/*.png
    print("%-22s %-6s %s" % ("", "", "  ".join(k.rjust(7) for k in
          ["P1", "CLIP", "STD", "dB", "b", "HALO", "LAP", "BGFG"])))
    for 名, pat in [a.split("=", 1) for a in sys.argv[1:]]:
        跑(名, sorted(glob.glob(pat)), 详细=os.environ.get("详细") == "1")
```
