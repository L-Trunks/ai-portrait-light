# 对照实验：十五轮是怎么打出来的

这份是过程记录。**结论都已经收进 [SKILL.md](../skills/portrait-light/SKILL.md)，这里回答的是「凭什么这么说」。**

方法很笨：每轮固定其他一切，只改一句话，同种子出 5~6 张，肉眼看 + 量八个数。
一共 ~120 张。下面按轮列，只留改变了结论的那些。

---

## 噪声底：先量摆幅，再谈效果

⛔ 第一件事不是做实验，是量噪声。**同一条提示词、同一个 seed、在同一套 ComfyUI 上重抽 5 次，
平均像素差 29/255** —— z-image 在这里不可复现。

所以任何改法的效果**必须大过这个摆幅才算数**。没有这一步，前面几轮的「好像变了一点」全是自欺。

---

## r1 · 堆形容词：五张几乎一模一样

五档强度的光线形容词（「柔和的逆光」→「强烈的丁达尔光柱」），全部堆在句尾。

结果：P1 6→7、HALO 1.43→1.42、dB 全是 −7~−9。**三项纹丝不动**，只有发梢挤出一点点轮廓光。

两个病灶：① 锚在末尾被前面 400 字描述稀释；② 场景句写的是「身后是干净的暖白色墙面」——
**物理上不可能逆光**，场景赢了光线。

## r2 · 决定性的一轮：改场景赢，挪位置没用

拆成两组单变量：

- M1/M2 只挪光线句的位置（尾 → 首 → 前后各一份）：**P1 / dB / HALO 全部不动**。
- M3/M4/M5 只把场景换成「身后是敞开的店门和门外明亮的街道」：**P1 7→12、CLIP 0.2%→3.8%**，逆光一次就出来了。

⭐ 推论：**光不是靠形容词写出来的，是靠把场景写成物理上只能这么打光。**
这是全部一百多张里最值钱的一条。

## r3 · 空气介质，以及「冷暗部」的反效果

三条单变量各自归因：

| 改动 | dB | 判定 |
|---|---|---|
| 只写「金色时刻」 | **−10.11** | 等于没有 |
| + 「空气里浮着被照亮的细小尘埃」 | **+1.37** | ⭐ 介质是把 dB 拉回正的那一手 |
| + 「暗部是偏冷的青灰色」 | b\* 掉到 −1.04 | ⛔ 反效果，模型把**整张图**一起吹冷了 |

⛔ 模型不会只冷暗部。暖冷分离只能靠**场景自带**（见 r4）。

## r4 · 场景排位：树林赢在自带暖冷分离

五个场景同配方对照，树林 dB **7.15**（参考片 8.44）最接近 —— 因为它天然有「暖光柱 + 冷绿树荫」，
不用另写那句反效果的冷暗部。河堤次之（HALO 1.64 最高，逆光草叶边缘全透）。

⛔ 但五张的人**还是被平光照着**。光是背景装饰，没落在她身上 —— 这条病一直拖到 r13 才解决。

## r6 · 柔焦提示词：零效果，必须放后期

参考片被形容成「轻微柔焦」，实测 LAP 参考 19、我们 200~275，锐了一个量级。
本轮五档柔焦写法单变量：

结果 **LAP 275→318（反而更锐）**，肉眼五张无差。

⛔ 柔焦这类**光学后处理**写进提示词完全无效，只能靠后期 bloom。
⚠️ 唯一有效的提示词侧软化是**加雾**（晨雾把 LAP 96 压到 55）——因为雾是场景里真实存在的东西。

## r7~r10 · 把光搬进近景，以及字数预算

光的配方对上参考片之后（P1 17 对 15.5、dB 8.64 对 8.44），并排一看，剩下的差全在**景别**。

⛔ 近景档必须**整条重写**，套原来的模板会被身形句和下装句把景别顶回全身。
这一条后来独立成了通用规律：**画框外的身体部位一个字都不能写**。

## r11~r13 · 推翻自己：不是「透光」，是构图

用三张外部参考照反推，发现和 r1~r10 的根本分歧：**光源本体不进画面**，
镜头前有遮挡物虚化成一片，光是被挡住之后漏进来的一部分，而不是整片逆光。

r12 单变量=相机句（满框 → 偏侧 → 侧脸）：

| | LAP | BGFG |
|---|---|---|
| 正脸满框 | 96 | 0.48 |
| 侧脸偏一侧 | **24.5** | **3.36** |
| 参考片 | 16.6 | 3.99 |

⭐ **构图比光更强。** 同一套光，只把人挪到画面一侧、只给侧脸，两个数一次对上参考片。

r13 固定「侧脸 + 耳后穿发 + 流动虚化背景」三件套，换 6 个场景验证泛化：**6/6 全成立**，
含非绿背景（樱花粉）和人造光（夜街，dB 27.1）。

⛔ 同时推翻了自己前一轮的验收线：CLIP=0 不是目标。入选的两张 CLIP 0.67/1.77，
被否的那张才 0.13、LAP 24.5 全场最好 —— **数值最漂亮的观感最差。**

## r14 · 扩展：正脸 / 半身 / 神态 / 多人

四组单变量，把只在「侧脸近景」验过的配方往外推：

- **正脸**：⭐ 推翻 r12 的「正脸会把光锁死成硬边缘光」。换光的写法即可，斜后光和环光**各 6/6**。
- **神态**：⭐ 笑能开到大笑露牙，**4/4**，不崩脸也不顶掉光。⚠️ 只在不挂 LoRA 时成立。
- **多人**：⭐ **4/4 人数全准**。⛔ 两处必须一起改（尾句人数 + 场景句主语），漏一处塌回一个人。
- **景别**：⛔ **半身 0/2** —— 相机句喊「从腰往上入镜」没用。
  景别是靠**画框内的身体/服装内容**撑出来的，不是靠相机句喊出来的。

## r15 · 冷雾档：四样叠加才成立

参考照里有一条**方向完全相反**的光路：正脸大特写、背景是一整面冷蓝纱帘、
背景比脸亮、b\* = −13.5（负的）、主光是她手里那朵被照透的花。

r14 已经把构图、冷调、纱帘、手捧花全部还原对了，差三样：花只是被照亮没在发光、雾太薄、整张比参考亮一档。
本轮做累加梯子：

**自发光 + 厚雾 + 压暗 + 柔，四样全叠加**才同时对上三项（P1 15 / STD 57.0 / b\* −12.1）。
单独去掉任何一样都掉。⛔ 改暖调直接废，去掉花直接废。

## 全身档：另外 36 张

近景档的规律**不能直接套到全身**：近景靠背景整个化成光斑，全身背景是实景，只能靠场景几何。

| | P1 | dB | b\* |
|---|---|---|---|
| 改造前 20 张 | 11.5 | 2.55 | 2.48 |
| 光感配方 36 张 | 20.0 | 1.92 | **8.73** |
| 参考片 | 15.5 | 8.44 | 13.19 |

两个坑：

- ⛔ **身后不能有一整面墙 / 一扇门 / 一排橱窗** —— 36 张里 10 张栽在这上面，
  墙把太阳挡在画框外，模型改从正面补光，全退化成平光。
  修法：站到**巷口 / 门洞 / 两根柱子之间的缺口正中**，10 张修好 8 张。
  剩下 2 张「场景全部内容就是一整面平面」的**直接换地点**，别硬凑。
- ⚠️ **太阳只挂在远处地平线上不算数**：数值最漂亮的那组（P1 15、b\* 15.1，全场最接近参考片）
  **人身上一点光都没有**，就是个好看的背景板。

## 出这成品十一张时又踩的两条

- ⛔ **光源离主体远 = 零轮廓光。**「夜晚天台的边缘，整片城市霓虹就在她身后」——
  霓虹在几百米外，人身上零轮廓光。同一条也砸过「太阳卡在她身后两棵树的树干之间」。
  ⭐ 判据换成**光源离她有多近**：齐腰的花枝之间 / 身后与肩同高的火盆 / 架在身后与头同高的射灯。
- ⛔ **景别没守住时，画框外的字段会被模型自己编出来。** 半身档按规矩不写下装，
  前提是画框真的切在腰上；一旦画框滑到膝盖，下半身进了画面而提示词里一个字都没有，模型就自由发挥。
  ⭐ 修法不是加字数，是**换景别**（改走中景，中景本来就要写下装），再用肯定句写死。

⭐ 还有一条方法上的：**挑片比改措辞收敛快。**
成品十一张是 30 张候选（每个位置 3 个种子）里挑出来的，10 个位置**全部**换掉了默认那张。
同提示词换种子的摆幅，比绝大多数措辞改动都大。

## 第三轮：三次推倒重来（成品十张，~90 张候选）

前十五轮解决的是「光对不对」。这三轮解决的是「好不好看」——
两个不同的问题，第二个问题的答案**不在措辞里**。

### 轮一：混排景别 → 十张只活了两张

第一版十张是近景 / 半身 / 中景 / 全身混排，交出去被砍掉八张。
把砍掉的和留下的两张并排量，差别不在光的措辞，在四条**结构性**指标：

| | 留下的两张 | 砍掉的八张 |
|---|---|---|
| 脸占画幅 | ≈ 1/3 | 1/5 ~ 1/20（全身那张脸只有 40 px）|
| 光源离人 | 贴手心 / 头后花架 | 书架两排之间、几十米外的霓虹 |
| 背景 | 全糊 | 书架、街道细节抢戏 |
| 色彩 | **一组补色对** | 单一色调铺满 |

⭐ 「补色对」这一条是这轮唯一的新发现，也是最省力的一条：
**光已经对了但画面还是平**，九成是因为整张图只有一个色温。

### 轮二：全部收成竖幅特写 → 光对了，但画面里只剩人

按上表把十张全部收进近景 / 特写，四条指标都补齐了，光也全部立住了。
但这一版又丢了另一样东西：**风景没了**，十张全是「一张脸 + 一片糊」。

这一轮里有一位连改三版都没改动：
「蒲公英 + 16:9 横幅 + 正脸大笑」，先放大相机句、再把上装削成只写领口、
再把光压到日落之后 —— **十二张出图景别一寸没动**，脸始终只占 1/5。
同一句特写相机换到竖幅（冬夜呵气那张），**一次到位**。

⭐ 由此得到两条：
- **横幅压不住特写**。16:9 的画框本身在要求横向填充，人只占半边时模型自动把另一半补成环境。
- **同一个方向改过三次、指标和肉眼都没动 → 卡的是结构（构图 / 画幅），不是措辞，该换概念了。**

### 轮三：环境人像（现在这十张）

横幅、人占画面高度 2/3 放在 1/3 处、另外 2/3 交给风景，光线时刻拉成
日出 ×2 / 夕阳 ×2 / 蓝调 ×1 / 深夜 ×5。十张探针跑完，四张要修，各修出一条结论：

| 症状 | 归因 | 修法 |
|---|---|---|
| 太阳飘到侧后方，轮廓光只剩一点（2 张）| 「和她的头一样高」只钉了**高度**，没钉方位 | 补「正好在她的头的**正后方**」 |
| 路灯被架到她正上方 → 顶光、脸压平 | **灯具名词自带高度语义**，形容词压不过它 | 换一个本来就矮的灯具：矮墙上的老式马灯 |
| 「日出的白花田」出来是大白天 | 「日出」只交代时间，没交代**天空长什么样** | 把天空写出来：太阳只露一半 / 天边橘红 / 天顶还是没褪的深蓝 |
| 掌心萤火虫在横幅里发闷发空 | 自发光档的三条内核没错，**载体的光量撑不起 2/3 的风景** | 换个亮得多的载体：帐篷杆上的营灯 |

最后一条值得单独说：自发光档的内核（唯一主光是自发光小物件 / 人压暗部 / 冷调里只有它是另一个颜色）
在特写里靠萤火虫就够，换到环境人像里三条一条没改、**只换了载体的亮度**，画面就立住了。
**先拆内核、再按画幅挑载体**，比照抄道具管用。

修完每位抽 3 个种子共 30 张，**十个位置全部选中了非默认种子那一张**。

### 补跑：换掉两位 cos（还原度优先）

定稿后又换掉两张 cos（原来的两位还原度不够），换成胡桃和 2B，带出三条：

- ⛔ **量词也是位置信息。** 「一**串**红灯笼挂在她身后」被理解成街道两边成排的灯笼，
  光源等于跑到她两侧去 → 边光全没。要一个定点光源就用**单数**。
- ⛔ **深色主体是「正后方」那条的例外。** 一身黑的角色把光源钉在正后方，
  光被身体整个挡住，出来是**剪影不是边光**。改成光源偏一侧 + 把亮线落在哪几条边上逐条点名。
- ⭐ **戏服字数优先于长度上限。** 字数上限 510 是**竖幅近景**标定的；横幅环境人像实测
  531~568 字五张景别全正常，卡在 510 只会让削长度的逻辑从戏服末尾砍分句 ——
  砍掉的正好是还原度最吃重的那几样（盘扣、腰带流苏、白长手套、羽毛状裁片）。
  上限抬到 660 后这些全保住了，景别照样没滑。**还原度靠的就是这些具体名词，删哪样画面就少哪样。**

## 第四轮：光全对了，还是只活了一张（~60 张候选）

第三轮交出去的十张环境人像，用户只留下 07（蝴蝶忍·紫藤）。
⛔ 关键在于：**被毙的九张里有三张（01 山脊云海 / 03 蓝调天台 / 05 银河营灯）
边光、贴身光源、补色对全部成立** —— 六步流程全过了，照样一张不留。
所以「光对不对」和「好不好看」是两道**独立**的关，前十六轮全在解第一道。

### 把 07 和被毙的九张并排比：差的是四条画面级的东西

| | 07（留下）| 被毙的九张 |
|---|---|---|
| 有没有一大片东西**自己在发光** | 整面被夕阳照透的紫藤，占 1/3 画幅 | 01 松枝 / 09 藤蔓叶是**不透光实体块**；03 窗灯、10 霓虹、05 银河**在几百米外** |
| 补色的**冷那一半** | 饱和紫，占 1/3 画幅 | 02 只有一条淡蓝棉布裙 → 整张读成全暖 |
| 有没有**一块真正的黑** | 黑立柱 + 黑和服 | 01/02/03/05 全是柔灰中间调 |
| 服装 | 蝶羽羽织 | 五张写真里**四张是奶白针织衫 + 牛仔裤**，同一件连出四张 |

⭐ 02（夕阳芦苇荡）是最好的反例：它**有**透光介质（芦花被照透），
但整张只有一个色温、也没有黑 —— 单靠第一条不够，四条要一起过。

### 这一轮新推翻 / 新确立的（都有对照）

- ⛔ **推翻本文档旧写的「齐胸高的花枝、芦苇、麦穗之间」可以当支架。**
  06 紫花田（鼠尾草齐腰）和 09 芒草坡（芒草齐胸）两张实证：太阳落到人的胯部或干脆没进画。
  ⭐ 原因是**开阔地里太阳的高度由地平线决定**，形容词压不过它。
  09 加一棵孤松（比她高）之后太阳盘一次就出来了。
- ⭐ **时间词决定太阳这个实体在不在画面里。** 06 连废四版：白花田 → 紫花田 → 紫花田+孤树
  → 蒲公英坡+风车（支架已经比她高得多），太阳**始终没进画**。
  唯一改动「黄昏」→「日落」+「太阳还没落下去、是一个明晃晃的圆盘」，四张全部出了太阳盘。
  对比 09 一开始写的就是「日落的芒草坡」，第一版就有太阳。
  **「黄昏 / 傍晚」只交代天色，出来是日落之后的余晖天。**
- ⛔ **「霓虹灯箱招牌」和「路灯」是同一个病**：名词自带「装在楼上」的语义，
  「比她高出一头」压不过它 → 04 第一版灯箱被挂到二楼外墙，人零边光。
  换成**自动贩卖机**（街景里唯一天生齐人高、还是整面发光板的东西）一次到位。
- ⭐ **单数还不够，要给画面里的尺寸。** 08 第一版已经写了「一盏很大的红灯笼在她正后方半米」，
  出图仍被画进远处那排里 —— 补一句「这盏灯笼在画面里很大、占了画面高度的四分之一」才钉住。
- ⛔ **支架远了等于没有支架。** 10 写「太阳卡在她身后两座深色石雕之间」，石雕在几十米外，
  太阳没进画、人身上一条边光都没有。有了支架也不能免掉「距离」那一维。
- ⛔ **黑锚不能挂在主体的衣服上。** 06 原计划靠流萤的黑制服当黑锚，
  但戏服由角色 / LoRA 决定、**不受场景句控制**，出来是白裙，黑锚当场消失。
  黑锚必须挂在场景里（树干 / 立柱 / 屋瓦 / 山脊剪影 / 风车木架）。
- ⭐ **发光介质在一组里互不重复，比换场景更能拉开差异。**
  这十张分别用了：金叶 / 樱花瓣 / 雾中光柱 / 雨丝+透明雨衣 / 火星 / 蒲公英绒毛 /
  紫藤花穗 / 落雪 / 芒草穗 / 喷泉水花。
- ⭐ **横幅环境人像字数上限可以到 660。** 实测 475~656 字十张景别全部正常
  （人占画面高度 3/4、风景占 2/3，没有滑档）。

## 第五~六轮：光对了不等于好看，第二关的两条判据（约 150 张候选）

### 第五轮 · ⭐⭐ 逆光只镶边不打脸 = 人不美

第四轮十张交出去又只留下一张。⛔ 关键：被毙的八张里，**边光、贴身光源、补色对全部成立**。
把留下的两张和被毙的八张并排比，唯一的差别是 **脸上有没有一块明确的亮面**：
留下的两张（篝火在侧前方照脸、夕阳穿过花架落到正面）脸上有亮面和暗面；
被毙的八张主光**全在人的后方**，脸只剩均匀的环境光 —— 光学上完全正确，但人不美。

⛔⛔ **不要写「光源在她正前方、和她的脸一样高」** —— 那正好是**镜头的位置**。
两次实证：「一整排小灯泡就在她正前方、和她的脸一样高」→ 灯泡被画到她身后；
「水晶吊灯在她正前方斜上方」→ 吊灯被画到头顶偏后。

⭐ 真能打到脸的只有三种：**侧前方 45°**（光源在画框边缘）、**正前偏下**（光源比脸低）、
**远处的正前方**（只有太阳够远，不占画面空间）。三种在这一轮各出一张，全部翻身。
⭐ 打脸光必须**把亮面和暗面都写出来**，再加一句眼睛里的反光点；
写「柔和地照亮她的脸」= 均匀光 = 等于没打。

⛔ 顺带一条：「脸颊被冻得有点红」六张**全部被画成两坨腮红** ——
**「因为 X 所以 Y」这种状态因果会被当成妆容画上去**（冻红 / 晒红 / 哭红同理）。

### 第六轮 · ⭐⭐ 背景「碎 vs 大」是唯一 100% 分得开的变量

第五轮十张挑出四张，连同之前的两张共六张。把**选中的六张**和**被毙的四张**并排比：

| | 选中的六张 | 被毙的四张 |
|---|---|---|
| 背景 | 海+天 / 一整面暗墙 / 暮蓝天 —— **元素少、块面大** | 夜市摊档 / 宴会厅一堆糊光斑 / 观众席人头 / 一片碎树干 |
| 几何线 | 窗棂格 / 海面反光带 / 木马顶棚弧线 / 花架长廊 / 桥架透视 | **一条都没有** |

⛔ **细碎堆叠的背景，虚化解决不了** —— 它提供的是"信息量"不是"结构"。
⭐⭐ 最稳的两个配方：**太阳盘 + 水面反光带**（反光带是一条从光源直指人的引导线，
一次同时满足"光源实体入画"和"有几何线"）、**长廊 / 隧道尽头的光源**。

按这条设计了 12 个概念 × 8 种子 = 96 张，最终定稿 11 张（7 写真 + 4 cos）。
⭐ 复刻验证：樱花隧道和千本鸟居都是照抄唯一一张三轮没被毙过的"紫藤花架"的结构，
两个都成立；「太阳盘 + 反光带」在海边、铁桥、冰湖、梯田上复刻四次。
⛔ 反例：火山熔岩那张几何线和大块背景都成立，但熔岩在地面、离脸太远，
写了「比她的脸低一点」也够不着，脸还是平的 —— **⑥ 成立不能替代打脸光**。

### 这两轮定下的收敛判据

流程从「六步 + 四条」重整成 **两道关**：§1 七步（光对不对）/ §2 六条（好不好看），
并把散在三处的五个坑（灯具高度 / 招牌高度 / 量词 / 镜头位 / 时间词）收成**一条定律**：
**名词自带的语义压得过任何形容词**。这是全套里唯一能预测新情况的规律 ——
写完一句先问"这个名词本身带不带位置 / 高度 / 数量 / 时间的常识"，带且相反就当场换名词。

## 附：度量脚本（`光感度量.py`）

八个数的口径。⛔ 先读 SKILL.md 第 6 节的「五条别当及格线」再用，
**数值全对也可能是废片，唯一可靠的验收是肉眼看发丝有没有一根根亮起来、人身上有没有轮廓光。**

```python
# -*- coding: utf-8 -*-
"""量一张图的「光感」指标，用来把参考片的感觉变成可比的数。
  P1     最暗 1% 的亮度。胶片/柔焦片黑不下去，越高越"奶"
  CLIP%  >250 的像素占比。逆光片必然有一片过曝
  STD    全图亮度标准差
  ΔB     高光区 b* 减 暗部区 b*。正=亮处暖暗处冷（黄金时刻的标志）
  b*     全图 b* 均值，正=偏黄
  HALO   高光周围 12px 环带的平均亮度 / 全图均值。柔焦会把光晕开
  LAP    中央 40% 区域的拉普拉斯方差（对焦是否实）
  BG/FG  边缘区 lapvar / 中央区 lapvar。越小背景越化
"""
import glob, os, sys
import numpy as np, cv2

sys.stdout.reconfigure(encoding="utf-8")


def imread(p):
    return cv2.imdecode(np.fromfile(p, dtype=np.uint8), cv2.IMREAD_COLOR)


def 量(p):
    im = imread(p)
    if im is None:
        return None
    h, w = im.shape[:2]
    if max(h, w) > 1400:
        s = 1400 / max(h, w)
        im = cv2.resize(im, (int(w * s), int(h * s)), interpolation=cv2.INTER_AREA)
        h, w = im.shape[:2]
    lab = cv2.cvtColor(im, cv2.COLOR_BGR2LAB)
    L = lab[:, :, 0].astype(np.float32)
    B = lab[:, :, 2].astype(np.float32) - 128.0
    g = cv2.cvtColor(im, cv2.COLOR_BGR2GRAY)

    p1 = float(np.percentile(L, 1))
    clip = float((L > 250).mean() * 100)
    std = float(L.std())
    hi, lo = L > np.percentile(L, 85), L < np.percentile(L, 25)
    dB = float(B[hi].mean() - B[lo].mean())
    bm = float(B.mean())

    # 柔光晕：高光核心向外膨胀 12px 的环带，看它比全图亮多少
    core = (L > 235).astype(np.uint8)
    if core.sum() > 50:
        ring = cv2.dilate(core, np.ones((25, 25), np.uint8)) - core
        halo = float(L[ring > 0].mean() / max(L.mean(), 1e-6))
    else:
        halo = 0.0        # ⛔ 光源出画时必为 0，别读成「没有光晕」

    y0, y1, x0, x1 = int(h * .3), int(h * .7), int(w * .3), int(w * .7)
    cen = float(cv2.Laplacian(g[y0:y1, x0:x1], cv2.CV_64F).var())
    m = np.ones((h, w), bool); m[y0:y1, x0:x1] = False
    gl = cv2.Laplacian(g, cv2.CV_64F)
    edge = float((gl[m] ** 2).mean())
    return dict(P1=p1, CLIP=clip, STD=std, dB=dB, b=bm, HALO=halo,
                LAP=cen, BGFG=edge / max(cen, 1e-6))


def 跑(名, 文件, 详细=False):
    rows = [(os.path.basename(f), 量(f)) for f in 文件]
    rows = [(n, r) for n, r in rows if r]
    if not rows:
        print("%-22s 没图" % 名)
        return
    ks = ["P1", "CLIP", "STD", "dB", "b", "HALO", "LAP", "BGFG"]
    if 详细:
        for n, r in rows:
            print("  %-30s %s" % (n[:30], "  ".join(("%7.2f" % r[k]) for k in ks)))
    med = {k: float(np.median([r[k] for _, r in rows])) for k in ks}
    print("%-22s n=%-3d %s" % (名, len(rows), "  ".join(("%7.2f" % med[k]) for k in ks)))
    return med


if __name__ == "__main__":
    # 用法：python 光感度量.py 参考=ref/*.png 我的=out/*.png
    print("%-22s %-6s %s" % ("", "", "  ".join(k.rjust(7) for k in
          ["P1", "CLIP", "STD", "dB", "b", "HALO", "LAP", "BGFG"])))
    for 名, pat in [a.split("=", 1) for a in sys.argv[1:]]:
        跑(名, sorted(glob.glob(pat)), 详细=os.environ.get("详细") == "1")
```
