# 人像光线配方

> **这是一套判断流程，不是词表。** 每一步只做一个决定，每个决定都有判据；
> 判不出来就停在那一步，别往下走，也别改措辞去撞。
>
> 证据来自 z-image（本地 ComfyUI）上 ~280 张**同种子单变量**对照
> （其中 76 张是 2026-08-30 补的成像系统那一轴），加六轮成品迭代
> （约 300 张候选，人工挑片，六轮里有四轮是整组推倒）。
> 逐轮数据在 `docs/对照实验.md`，**30 张成品和它们各自的完整提示词在 `docs/配方全文.md`**
> （配图在 `assets/`，编号一一对应）。
> ⭐ **要直接抄就抄 12~30 那 19 条**，它们是按本文件重出并人工挑过的。
> ⚠️ 01~11 写在 2026-08-29 归因之前，其中七条仍带着「和她的脸一样高」和
> 「眼睛里有一颗清楚的反光点」两个已知 bug（第 3 步② / §8①）——
> 文档里没改它们的正文（那些字就是配图的来源），但逐条标了复用时要改成什么。
> 提示词是**纯中文整段**，粘到豆包 / 即梦 / 通义同样成立，不用拆词、不用配负向。

## 0. 先看这个：这是两道独立的关

```
      要写一条              图已经出来了
          │                      │
          ▼                      ▼
   §1 七步装配 ─────────┐   §5 诊断表（从症状进）
   （第一关：光对不对）   │        │
          │              │        └──► 回到对应的那一步
          ▼              │
   §2 六条画面级判据 ◄───┘
   （第二关：好不好看）
          │
          ▼
      §3 验收清单（只用肉眼）
```

⛔⛔ **过了第一关不会自动过第二关。**
实证：一组十张里，有三张的边光、贴身光源、补色对**全部成立**（第一关全过），
交出去一张没留下 —— 差的全在第二关。
六轮迭代里，**有三轮是"光完全正确但整组被毙"**。第二关不是锦上添花，是另一半工作量。

## 0.5 ⛔⛔ 这份文档最容易被用错的方式：把每一条都套在每一张上

**§1 和 §2 是判据清单，不是每张图的施工单。**
一张图先定它**靠什么成立**，再只把那一两样拉满；其余的条目**允许留白**。

⭐ 这条是拿 5 批 60 条提示词、180 张候选换来的（成品全部在 `../../assets/`）：

| 批 | 做法 | 画幅 | 挑中率 |
|---|---|---|---|
| v9 | 每条都上满：打脸四件套 + 几何线 + 黑锚 + 补色对 + 皮肤档 + 成像句 | 16:9 | **7/12** |
| v10 | 同上，一条没减 | 竖幅 | **1/12** |
| v11 | 同上 + 主光全部换成冷光 | 竖幅 | **1/12** |
| v12 | **每条只定一个成立点**，其余不强求 | 竖幅 | **6/12** |
| v13 | 同 v12，只把人物句的「亚洲」锚点加回去 | 竖幅 | **4/12** |

⛔⛔ **这张表最重要的一行是 v9 的 7/12** —— 它证明「上满」本身不是错的，
**错的是拿同一套骨架连出第二批**：7 → 1 → 1。而成立点那套连出两批都稳（6 → 4）。
⚠️ 诚实交代两个混淆项：v9 是 16:9 而 v10/v11 是竖幅，且 v9 出现在最前面
（用户已经从 v9 挑走 7 张，v10/v11 的边际新鲜度天然更低）。
三个原因分不开，但**可操作的结论是同一条**：

> **一套骨架只能撑一批。第二批要么换成立点，要么换轴（画幅 / 色温 / 成像系统），
> 光换穿搭和场景是不够的。**

⛔ **"全都对"会亲手做出同质化，而且是跨批次的。** v10 那批 12 条里的实际情况：
**10 条的动作是同一句「转过头看向镜头，眼神很稳」，12 条机位全是平视** ——
因为注意力全花在把六项判据填满，动作和机位就退化成了默认值。

⭐⭐ **先写一行「成立点」再动笔**，就一两个词。可用的成立点（来自实拍）：

| 成立点 | 那张图靠什么撑住 | 例子 |
|---|---|---|
| **场景 + 镜头** | 一个有说服力的地方 + 一个不寻常的机位 | 昆虫视角从花丛缝隙里看她 / 藏在果树枝叶后 |
| **光线 + 妆面** | 一种光打在一张脸上，别的都让位 | 午后窗光 + 柔雾 + 奶油裸妆 |
| **场景关系 + 成像方式** | 人和这个地方的关系 + 一种记录方式 | 夜间办公室白板 + 直闪 |
| **道具 + 光线** | 一件强身份道具 + 一束窄光 | 暗调琴房 + 大提琴 |
| **成像方式 + 场景** | 一种质感统治全画面 | 热带旅馆走廊 + VHS 过曝 |

⛔ 定了成立点之后，**§2 那六条只查"有没有硬伤"，不当作必填项**。
⚠️ 唯一不能省的是 §1 第 2 步那个决定（打脸还是镶边）—— 但**它允许答"这张不需要打脸"**：
实拍里挑中率最高的几张（白雾逆光的旧室、树冠漏光的果园、窗光的卧室）
**一条打脸四件套都没写**。

---

⭐ 如果只记一件事：**别写「唯美的逆光」，去写「太阳在她左前方 45 度的两栋楼之间压得很低，
正斜劈在她的半张脸上」。** 其余所有规矩都是这一句的推论 ——
它同时做到了三件事：**写场景不写形容词**（§1 第 4 步）、**钉方位角而不是"和脸一样高"**（第 3 步②）、
**打脸而不只是镶边**（第 2 步）。

⚠️ 早期版本这句写的是「太阳……在她身后两栋楼之间的缝里、和她的头一样高」。
那是**镶边光**的例子，物理上没错，但它正是后来 §1 第 2 步实证「八张全毙」的那一类
—— 放在最显眼的位置当口诀会把人往坑里带，已经换掉。

## 1. 第一关：七步装配（解决「光对不对」）

顺序不能换。

### 第 1 步：选构图族 → 这一步决定后面所有写法

先问**这张图要给人看什么**：

| 要看的是 | 族 | 画幅 |
|---|---|---|
| 脸和情绪 | **特写** | ⛔ 只能竖幅 |
| 人，背景只是氛围 | **近景 / 半身** | 竖幅横幅都行 |
| 人**和**这个地方 | **环境人像** | ⛔ 只能横幅 |

⛔ **画幅已经定死时反向约束族**：16:9 里做不出特写（§7.1 有 12 张实证）。
画幅和族冲突 → **改画幅**，不要改措辞。

**产出：相机句。**

⚠️ **相机句分画幅两套，别混用** —— 「左边三分之二让给背景」这种横向分配在竖幅里没有意义，
写了模型会自己去挤出一块横向空白，反而把人推小。

**16:9 横幅：**
- 近景：`她在画面右边三分之一处、从胸口往上入镜，脸占画面高度的三分之一，左边三分之二让给背景。`
- 半身：`她在画面右边三分之一处、从腰往上入镜，左边三分之二让给背景。`
- 环境人像：`一张 16:9 横幅的真实照片。她站在画面右边三分之一处、从膝盖往上入镜，身高占满画面高度的四分之三，左边三分之二整个让给风景。`

**竖幅 2:3：**
- 特写（⛔ 只有这个画幅做得出）：`她的头和肩膀几乎填满整个画面：额头顶到画框上沿，下巴落在画面正中，两边脸颊快要碰到画框左右两边。`
- 近景：`她在画面中心偏右、从胸口往上入镜。`
- 半身：`她在画面中心偏右、从腰往上入镜。`

⛔ **同时决定写到哪个部位为止**（写了哪个部位就等于把画框拉到哪个部位，§8②）：
特写写到**领口**、近景写**上装**、半身写**上装**、中景写**下装 + 腿**、全身写**鞋 + 地面**。

### 第 2 步：定光位 —— 这张要打脸光，还是要镶边光？

⛔ **这一问必须先答。答错了，后面每一步都做对也是废片。**
实证：一组十张里八张的光**在光学上完全正确**（边光、贴身光源、补色全成立），
但主光全在人的**后方** —— 脸只剩均匀的环境光，没有立体感也没有光泽，**人就不美**，八张全毙。

| 你要的 | 主光位置 | 脸上会是 |
|---|---|---|
| 轮廓光 / 发丝光 / 剪影感 | 正后方 / 侧后方 | ⚠️ 只有环境光 —— **必须另外补一个能照到脸的光源**，否则人不美 |
| 打脸光（**人物要美就选这个**）| 见第 3 步② 的两种写法 | 一块**明确的亮面** + 一块暗面 |

⛔⛔ **不要写「光源在她正前方、和她的脸一样高」** —— 那个位置正好是**镜头的位置**。
模型不肯让光源挡住镜头，一律把它挪到人身后或头顶去（→ §4 那条定律的第 4 个实例）。
**具体该怎么写，全部在第 3 步②**，这里只决定「打脸还是镶边」。

⭐ 打脸光要**把亮面和暗面都写出来**。写「柔和地照亮她的脸」= 均匀光 = 等于没打。
**四件套，缺一件脸就立不起来：**

```
把她的额头、颧骨和鼻梁照得发亮，鼻子侧面下方留下一小块三角形的亮斑，
另外半张脸整个落在柔和的暗部里；睫毛在被照亮那半边的脸颊上投下细影
```

⛔ 第三件（暗面）**必须和前两件一起出现**。只写「脸落在柔和的暗部里」而不写亮面，
就是全暗脸 —— 那一档 38 张全废过。⚠️ §7.1 特写族说的"第三件套"指的就是这里的暗面，
**不是在四件套之外再加一句**。

⭐ 再补一句**眼睛里的反光**，脸立刻"活"：
```
她两只眼睛里各有一小点同样大小、同样位置的暖金色反光
```
⛔⛔ **一个字都不要写成「眼睛里有一颗清楚的反光点」** —— 「一颗」是数量信息，
模型照做，只点亮**一只**眼。这条的完整归因和通则见 §8①。

### 第 3 步：选光源，并钉死三个维度

**先问「这个场景在这个时刻，什么东西是亮的」：**

| 场景 | 主光源 |
|---|---|
| 日出 / 日落户外 | 太阳（低角度，天然落在头肩高度，最省事）|
| 正午户外 | ⚠️ 没有低位光源 → 改时间，或退回第 1 步换族 |
| 夜晚有人造光（街 / 舞台 / 庭院）| 场景自带的：霓虹 / 灯笼 / 灯箱 / 火盆 / 射灯 / 自动贩卖机 |
| 夜晚无人造光（山顶 / 荒野 / 湖边）| ⛔ 必须自带一个：营灯 / 提灯 / 篝火 / 她手里的发光物（→ §7.4）|
| 室内 | 窗 / 门缝 / 矮处的灯具 |

**再钉三个维度，缺一个就飘：**

**① 距离** —— 判据：**光源离她能不能到半米~两米**。
「整片城市霓虹就在她身后」（几百米外）= 零轮廓光，出来是好看的背景板。
到不了这个距离 → **换光源**，别改措辞。

**② 方位** —— 高度和方位要**一起写**：
`太阳正好在她的头的正后方、从两根松枝之间跳出来、和她的头一样高、正对着镜头`
只写「和她的头一样高」，太阳会飘到侧后方去。
⚠️ **深色主体是例外**，判据见 §6.1。

⛔⛔ **「和她的脸／头一样高」这句只能用在逆光（正后方）上，绝不能用在主光上。**
写「光源在她**正前方**、和她的脸一样高」= 在描述**镜头所在的位置**，那儿不可能有灯，
模型只能把它挪到唯一说得通的地方 —— **她背后**。于是本想要的正面主光变成真逆光：
脸上一点直射光都没有，`三角亮斑 / 睫毛投影 / 眼里的反光` 这些要件模型只好瞎编，
**脸崩，而且眼睛上会冒出一个突兀的单点闪光**（2026-08-29 两批实拍，13 条里 3 条全废）。

⭐⭐ **只有两种写法验得住**，共同点是**物理上没法被挪到人背后**：

| 写法 | 为什么挪不走 | 例句 |
|---|---|---|
| **侧前方 45°** | 「左前方 45 度」是**方位角**，无歧义 | `太阳在她左前方 45 度的树梢上压得很低，正斜劈在她脸上` |
| **正前偏下** | 「比她的脸低一截／低半米」是**高度差**，无歧义 | `一盏暖橘的灯箱在她正前方、比她的脸低半米的地方直直照上来` |

⭐ 判据一句话：**写方位角或高度差，别写「和脸一样高」。**
2026-08-29~30 四批共 92 张里，这两种一次没翻过车（光位配比一直是 6/6）。

⛔⛔ **曾经有第三种「远处的正前方太阳」，2026-08-29 已整档废掉，别再写。**
理由是它没有第三个可钉的维度 —— 方位角是 0、高度差要靠「压得很低」这个**形容词**去撑，
而形容词压不过「正前方」这个名词自带的镜头位（§4）。实拍 3 条（泳池 / 向日葵 / 海雾栈桥）
**全部退化成真逆光，3/3 脸崩 + 单眼冒闪光**。⚠️ 它在旧版本文里被当成第三个选项写过，
如果你在别处（包括 `docs/配方全文.md` 里的 02 / 05 两条）看到这个写法，那是**未修的旧文**
（那份文档里 01~11 每条带这个写法的下面都标了要改成什么；**12~30 已经没有这个写法**）。

**③ 支架** —— 光源要架到头肩高度，靠场景里一个东西托住。

⛔ **判据是三条，缺一条等于没有支架：有一道缝 / 比她高 / 离她两米内。**

| 场景类型 | 支架 |
|---|---|
| 自然 | 两棵树干之间 / 一棵孤树分开的两根主枝之间 / 岩石 / 断墙 |
| 城市 | 两栋楼的缝 / 巷口 / 门洞 / 桥洞 / 棚架立柱 |
| 室内 | 门框 / 两扇障子门之间 / 书架之间的窄缝 |
| 人造 | 花架立柱 / 鸟居 / 晾晒的床单之间 / 风车叶板之间 / 舞台桁架 |

- **有缝** —— 没有缝的三种直接换地点：开阔天空、光秃秃的海平线、身后一整面墙 / 一扇门 / 一排橱窗。
- ⛔ **比她高** —— 齐胸高的花穗、芦苇、麦浪**不是支架**（旧版本文写过，2 张实证推翻）。
  ⭐ 原因：**开阔地里太阳的高度由地平线决定**，形容词压不过地平线，齐腰的东西托不住它，
  太阳只会落在人的胯部或干脆掉到地平线下。要抬到头肩高度，必须给一个
  **比她高、并且在画面里画出来的实体**（树 / 花架 / 建筑 / 风车）。
- ⛔ **离她两米内** —— 「太阳卡在她身后两座石雕之间」，石雕在几十米外 → 太阳没进画、
  人身上一条边光都没有。有了支架也不能免掉「距离」那一维。

⚠️ 这一步还有三个坑（灯具名词的高度 / 量词 / 时间词），它们是**同一条定律**的实例 → §4。

### 第 4 步：写场景句 —— 光是靠场景写出来的，不是靠形容词

全流程最贵的一条。**把场景写成物理上只可能这么打光**，而不是形容光。

`场景句 = 时间地点 + 光源在哪（第 3 步的三个维度）+ 背景被照透 + 天空长什么样`

```
黄昏的老街，一盏很大的红灯笼就挂在她正后方半米、与她的头同高、正对着镜头，
右边三分之二是向远处收进去的整条青石板老街，木格窗被照成发亮的暖橙色，
天空是刚暗下来的深蓝色
```

三条硬要求：

- ⛔ 背景写**「被这个光源从背后照透成发亮的暖金色」**；
  ⛔ **不能写「身后是逆着光的树丛」** —— 会被画成实体暗块，一个光斑都不出。
- ⛔ **时间词不交代天空长什么样**。只写「日出的白花田」出来是大白天。
  要把天空画出来：`太阳只露出一半、天边是浓的橘红色、天顶还是没褪干净的深蓝色`。
- **背景的详略跟着族走**：特写 / 近景写死「糊成一片没有细节」；
  环境人像**反过来要有细节**，并且收尾句里的「浅景深」要摘掉。
  ⚠️ 这条和 §2 ⑥「要有一条几何线」看着打架，其实不打架 ——
  **特写 / 近景的几何线只占画角的一小段，不是贯穿画面的那种**。写法固定成这样：
  > `右上角只露出一小块砖墙和它那条笔直的边线；其余整片是没有细节的深褐色暗背景。`
  贯穿画面的长几何线（透视走廊、反光带、栏杆）是**半身和环境人像**才用得上的。

### 第 5 步：加一句空气介质

没有介质，光就只是背景亮，不成氛围（实测暖冷分离 −10.11 → +1.37）。
跟着场景选：尘埃 / 飞絮 / 花瓣 / 水雾 / 雪粒 / 火星 / 干冰烟 / 细雨丝 / 晨雾。

```
空气里浮着被照亮的细尘
```

### 第 6 步：写光落在哪 —— 逐条点名，别只说「有轮廓光」

⭐ **句式骨架**（南鸢写真 skill 给的，和我们第 3 步 + 第 6 步是同一件事的两种拆法，
可以直接当填空模板用）：

```
【光源】从【方向】进入，落在【皮肤 / 发丝 / 服装 / 道具 / 前景】上，
形成【高光 / 阴影 / 眩光 / 颗粒 / 柔雾 / 亮部轻微溢出】。
```

三段各自的候选词，卡住时从这里挑：

| 段 | 候选 |
|---|---|
| **光源** | 午后窗光 / 门缝斜光 / 树荫斑驳光 / 墙缝硬光 / 低角度落日 / 灯箱 / 橱窗 / 自动贩卖机 / 矮处的台灯马灯营灯 / 火光 / 水面反射补光 / 植物漏光 |
| **落点** | 脸颊 / 鼻梁 / 锁骨 / 肩颈 / 发丝 / 手臂 / 胸口衣料 / 薄纱边缘 / 金属饰品 / 前景花瓣 |
| **结果** | 局部高光 clipping / 轻微过曝 / 硬阴影切割 / 高光弥散 / 银色 bloom / 边缘泛光 / 柔焦高光 / 草帽筛孔光斑 / 背景压暗 / 浅景深高亮虚化 |

⛔⛔ **原表的「光源」一栏被删掉了四项，因为它们和本文件其它地方直接打架** ——
词表这种东西最容易变成"推荐了自己禁止的东西"，记在这里免得下次又抄回来：

| 删掉的 | 和哪一条打架 |
|---|---|
| `正午硬阳光` | 第 3 步：正午没有低位光源，脸必被压平 → 要么改时间要么换族 |
| `CCD 直闪` / `机顶闪光` / `柔化闪光` | 这三个是**成像系统不是光源**（§6.4），塞进光源栏会让人**同时定义两次**。⚠️ 不是说不能用直闪，是说它该写在成像系统那一栏，而且只在「这个场景真会有人开闪光灯」时才用 |
| `窗外白雾逆光` | 第 2 步：纯逆光只镶边不打脸 = 人不美（八张全毙那一组） |

⛔ 两条硬约束：
- **光必须明确打在人身上**，不要只把光写在亚克力、玻璃、桌面或背景上。
- **"打在人身上" ≠ "整张脸都反光"**（下一小节 6b 展开）。
  `轻微过曝` 必须指明落点，不能当成覆盖整张脸的统一结果。

**能透光的主体**（浅色头发 / 薄纱 / 飞起来的碎发）：
```
她外圈飞起来的碎发被这道光一根一根照透、亮成细细的暖橘色亮线，
肩线和手臂外缘都镶着一条暖金色的亮边
```

**深色主体**（判据见 §6.1）：光源偏一侧，把亮线**逐条点名落在哪几条边**：
```
把她银白色头发的外圈、右边肩膀的边缘和右臂的外侧各照出一条清晰的暖金色亮线
```

⚠️ **特写族不需要在这里额外加句子。** 第 2 步的打脸四件套里那件「另外半张脸整个落在
柔和的暗部里」就是 §7.1 说的"好看开关"，⛔ **别再单写一句「脸的其余部分落在暗部里」** ——
单写它（不带亮面）就是全暗脸，那一档 38 张全废过。

⛔ **光斑落点要正向限定**：`金色光斑全部落在她身后很远的虚化背景里` ——
不限定它会飘到脸上变成一颗橘色圆饼。

#### 第 6b 步：光落到脸上之后 —— 皮肤**纹理**和皮肤**反射**是两个独立的轴

> 📖 这一小节折自 **南鸢写真 skill**（MIT，见 §11），是外部来源对本配方最大的一处补强。

**写了"真实毛孔"不等于写了"皮肤怎么反光"。** 前者只管毛孔、绒毛、细纹和肤色变化，
后者是另一件事，**必须单独写一句，而且写法随景别变**：

| 景别 / 情形 | 反射怎么写 |
|---|---|
| **默认**（没有水光肌 / 汗湿 / 参考证据）| 自然半哑光或克制缎光；T 区高光受控，脸颊以柔和漫反射为主 |
| **特写 / 近景** | **要按区域写**：额头大面保持半哑光，鼻梁只留一条窄高光，鼻尖与眼下不形成大片白亮，脸颊保留柔和的肤色层次 |
| **半身 / 全身** | 只留**一条**高信号约束（「自然缎光皮肤，T 区高光克制，双颊不湿亮」），别堆完整皮肤教程 |
| **要汗光 / 湿亮** | 只有炎热运动、刚跑完、雨水、泳池或明确要水光肌时才加，并且要写**发生区域 + 场景因果**（发际线和鼻尖少量汗光），不是全脸均匀油膜 |

⛔ **`水润唇 / 玻璃唇 / 湿润眼妆` 只作用在对应的五官区域**，不会自动扩散成
额头鼻翼双颊的连续湿亮 —— 反过来说，**你不单独把边界写死，模型就会让它扩散**。

⛔ **高风险组合**：`直闪 + 正午硬光 + 轻微过曝 + 清透妆/水润唇 + 面部近景`。
这一组必须**同时给出正向的反射控制**，不能只在末尾补一句"不要油腻"：

```
自然半哑光底妆，额头与双颊保持柔和漫反射，T 区只有克制的窄高光，
水润质感只保留在唇部；直闪提亮眼神和服装边缘，不在脸上形成连续油膜。
```

⭐⭐ **返工方向是反直觉的**：已经出油腻感了，**先减少覆盖脸部的闪光强度和过曝范围，
再补区域反射**；**不要只去加"真实毛孔、真实纹理"** —— 那样得到的是
南鸢原文命名的那个失败态：**「有毛孔的油亮皮肤」**。

⭐ **这条推翻了我们自己"干净 ↔ 真实二选一"的旧结论。** 准确地说不是推翻，
是那个二分只覆盖了「纹理有无」这一个轴，**反射是独立的第二个轴**：
干净档也得写反射（半哑光），痕迹档也不该全脸湿亮。
**本机 z-image 3 种子近景实测：**写全「真实毛孔 + 半哑光底妆 + T 区窄高光 +
双颊漫反射 + 水润只在唇部」的一档，稳定胜过只写纹理的一档。

⛔⛔ **但反射写对 ≠ 脸上没有腮红**（这条是我们自己的坑，南鸢那边没有）。
cfg=1 时负向失效，而**妆容名词自带整套腮红先验**（`桃粉甜美妆` / `玫瑰水光妆` /
`青苹果氧气妆` / `Y2K 桃粉玻璃唇妆` 这类），名词的语义压得过形容词（§4）——
一律换成「很淡的裸妆」，再补一句正面描述脸颊肤色的话。详见 §8 ⑦。

### 第 7 步：配第二色温 —— 补色对

**光已经对了但画面还是平，九成是因为整张图只有一个色温。**

| 主光是暖的 | 冷的那一半去哪找 |
|---|---|
| 暖金落日 / 日出 | 天顶还没褪的深蓝、远山的冷蓝剪影、雾蓝色的衣服 |
| 暖橘灯（灯笼 / 钠灯 / 马灯 / 橱窗灯箱）| 刚暗下来的暮蓝天、冷蓝的雪夜、深青蓝的街 |
| 火橘 / 熔岩 | 深蓝紫的夜空、远处冷灰的山影 |

| 主光是冷的 | 光源实体可以是 | 暖的那一半去哪找 |
|---|---|---|
| **青蓝霓虹 / 屏光** | 霓虹招牌 / 自动贩卖机 / 一整列机柜指示灯 / 街机屏 / 显示器 / 车厢灯管 | 侧后方一块暖橘灯牌、拉面店暖帘、一扇暖黄窗、一枚暖橘电源灯 |
| **蓝紫射灯** | livehouse 射灯 / 天象厅投影 / 舞台顶排灯 | 台下一片暖橘荧光棒、过道的暖橘引导灯带 |
| **冷蓝月光 / 雪地 / 冰面** | 月亮 / 雪后未升高的天光 / 透光的冰壁 | 远处一扇暖黄窗、场边一盏没关的暖橘灯、地平线一线没褪的暖橘暮色 |

一句话记法：**主光暖的，去天空和远景找冷的；主光冷的，在近处塞一个暖光源。**
⚠️ **唯一不配补色对的是 §7.4 自发光档** —— 那一族的内核就是"全画面只有那个光源是另一个颜色"，
给它配暖补色等于把它拆了。

⛔⛔ **冷光路子最大的风险不是写不好，是根本想不起来写它。**
2026-08-30 盘过一次：35 张成品素材里**主光是冷色的只有 1 张**，
其余全是落日 / 篝火 / 灯笼 / 橱窗灯箱 / 窗光。
⭐ 根因值得记住 —— **它是从"参考哪一套 register"继承来的**：
那批素材照着一份外部写真 skill 的「高频风格入口」建，而那 9 条入口
（CCD 街拍 / 直闪暗调 / 海边 / 热带 VHS / 旧室逆光 / 花丛 / 果园 / 柔雾室内 / 暗调道具）
**主光全是日光、闪光或暖灯，一条冷光入口都没有**。
⛔ **抄别人的风格清单时，先查它这张清单本身缺哪一维**，否则你会连它的盲区一起抄进来。

⚠️⚠️ **同一天还栽了这条的另一半，更隐蔽：抄模板要先问它假设了什么外部输入。**
那份外部 skill 的人物模块只写「成年年轻女性」、不写人种 ——
因为**它默认有一张人物身份参考图在锁脸**（它整节都在讲身份参考与风格参考怎么分工）。
我们这条线是纯文生图、没有参考图，照抄之后 **12 张里 4 张的脸漂成了欧美/混血**，
而且脸一漂，原本压得住的腮红也跟着回来了（正向脸颊描述是按亚洲脸写的）。
⭐ **通用形式：别人省掉的那一项，往往正是他们那边由别的东西保证的。**
抄之前先列一遍它假设了什么（参考图 / LoRA / 后期 / 人工挑片 / 负向真生效），
逐条确认你有没有；没有的，那一项就得自己写回来。

## 2. 第二关：六条画面级判据（解决「好不好看」）

⛔ **§1 只保证「光没错」。这六条决定「好不好看」，是独立的一关。**
它们不是从光学推出来的，是把**被选中的**和**被毙的**成品并排比出来的。

⭐ **⑥ 是目前唯一一条能 100% 分开"选中"和"被毙"的判据，先查它。**

### ⑥ 背景要「少而大」，并且带一条干净的几何线

| | 被选中的 | 被毙的 |
|---|---|---|
| 背景 | 海+天 / 一整面暗墙 / 暮蓝天 / 雪街 —— **元素少、块面大** | 夜市摊档 / 宴会厅一堆糊光斑 / 观众席人头 / 一片碎树干 |
| 几何线 | 窗棂格 / 海面反光带 / 木马顶棚弧线 / 花架长廊 / 桥架透视 / 梯田曲线 | **一条都没有** |

⛔ **细碎堆叠的背景，虚化解决不了。** 摊档、人群、一堆散落的光斑，糊了照样把画面搅浑
—— 它们提供的是"信息量"不是"结构"。

> 📖 **病因（折自南鸢写真 skill，§11）：抢戏的是锐度和微反差，不是亮度。**
> ⛔ **「背景比人物暗」不能代替信息层级** —— 暗背景照样可能因为高锐度、
> 高微反差和密集高光而显得繁杂。这解释了上面那条"虚化解决不了"：
> 虚化降的是锐度，降不掉密集高光点。
>
> 它给的分层比我们的"少而大"更细，**四级**，写提示词时逐级点名：
> **主体清晰区 → 主导大形 → 次级细节 → 连续低细节区（留白）**。
> - 背景靠大叶面 / 墙面 / 窗洞 / 天空 / 深色阴影撑起来的：保住这些**主导大形**，
>   把次级枝叶、纹理、远景物体**合并成低反差低锐度的色块**；
>   ⛔ 不要同时要求"每层背景都清楚、每片叶脉都看得见"。
> - 背景本身就是繁密装饰或城市信息流的：密度可以留，但**仍要指定主体清晰区和视觉落点**，
>   不能让所有细节拥有同等的对比与锐度。
> - **景深、锐度、微反差要分区写**：主体清晰不代表背景要用同一档锐度。

⭐ 两条修法，二选一或都要：
- 给一条**贯穿画面的线**：透视走廊（花架 / 鸟居 / 樱花隧道 / 桥架 / 街道 / 车厢）、
  水面反光带、梯田曲线、栏杆、窗棂、一排灯、山脊、地平线。
- 把背景**换成一两块大东西**：海 + 天 / 雪坡 + 天 / 一整面墙 / 一整片暮色。

⭐⭐ **两条出片率最高的配方，优先试：**

| 配方 | 为什么强 |
|---|---|
| **太阳盘 + 水面（冰面 / 湿路面）反光带** | 反光带本身就是一条**从光源直指人**的引导线，一次同时满足⑤和⑥，还自动带上①和② |
| **长廊 / 隧道尽头的光源** | 透视线把视线送到光源上，再送回人身上（紫藤花架、樱花隧道、千本鸟居、地下通道）|

### ⑤ 光源实体要入画

太阳盘 / 一排灯泡 / 一扇窗 / 一堆篝火 / 一盏灯笼 / 一块橱窗灯箱 —— **把那个东西本身画出来**，
让人看得见光是从哪来的。
⚠️ 和①不是一回事：①要的是「被照的一大片东西在发光」，⑤要的是「光源本体在画面里」。

### ① 要有一大片「被主光照透、自己变成光源」的介质，占画幅 ≥ 1/3

光只落在人身上不够。判据是**这片东西自己在不在发光**。两种常见的假货：

| ⛔ 不算 | 为什么 |
|---|---|
| 松针 / 藤蔓叶 / 砖墙 / 铁架 | 不透光，背光时是实体暗块 |
| 城市霓虹 / 窗灯 / 银河 / 远处的云海 | 亮，但在几百米外，且不可能被"照透" |

可透光清单（都验过）：花穗 / 花瓣 / 落叶 / 芒草穗 / 蒲公英绒毛 / 雪帘 / 雨丝 / 火星 /
水花 / 雾里的光柱 / 薄纱或透明雨衣。
⭐ 一组里让它们**互不重复**，比换场景更能拉开一组图的差异。

### ② 补色对要比面积和饱和度

不是「画面里有两个色温」就算。判据：冷的那一半**占不占得到 1/4 画幅**、是不是饱和色。
一整片饱和紫的花架 ✅；一条淡蓝棉布裙 ❌（整张仍会读成全暖）。

### ③ 画面里必须有一块真正的黑

全是柔灰中间调 = 发闷、不抓眼。
⛔ **黑锚要挂在场景里，不能指望主体的衣服** —— 戏服由角色 / LoRA 决定，不受场景句控制
（写好的黑制服出成白裙，黑锚当场消失）。
挂场景的：树干 / 立柱 / 屋瓦 / 山脊剪影 / 湿黑路面 / 风车木架 / 车厢暗部。

### ④ 服装是画面元素，不是背景板

一组十张里连出四张「奶白针织衫 + 牛仔裤」，光再对也只是随手拍。
判据：一组里**有没有重复穿同一件**；单张看**这身衣服有没有颜色和廓形**。

## 3. 验收清单 —— 只用肉眼，分两组

**第一组（光对不对）：**

1. 发丝 / 轮廓有没有**一根根**亮起来？ —— 没有 → §5 诊断表
2. 画面里有**几个**色温？ —— 只有一个 → 第 7 步
3. 主体够不够大？脸占画幅 < 1/5 → 第 1 步换族

**第二组（好不好看）—— ⛔ 第一组全过也可能这组全废：**

4. **背景是「少而大」还是「细碎堆叠」？找得出一条贯穿画面的线吗？** → §2 ⑥
5. **脸上有没有一块明确的亮面**（分得出亮面和暗面，不是均匀的环境光）？ → §1 第 2 步
6. **光源实体在不在画面里？** → §2 ⑤
7. 有没有**一大片东西自己在发光**？ → §2 ①　冷色够不够大够不够艳？ → §2 ②
8. 有没有**一块真正的黑**？ → §2 ③　这身衣服是不是路人装？ → §2 ④

**一组图还要多一问：十张摆在一起，像不像同一张？**
单张都成立、一组读起来是一张，就是模板化。沿**四个**轴拉开，缺一个就还是一个味道：

| 轴 | 怎么算拉开了 | 怎么数 |
|---|---|---|
| **景别** | 特写 / 近景 / 半身 / 中景轮着来 | 各占多少 |
| **光位** | 侧前 45° / 正前偏下 / 侧后 / 正后 / 自下而上 | 各占多少 |
| **场地类型** | 室内 / 海 / 街 / 雪原 / 山野 / 花树 / 工业…十张不重样 | 有没有重的 |
| **⭐ 主光色温** | 全组同一个色温 = 一个味道 | **冷主光张数 / 总数**，< 1/4 就是病 |
| **⭐⭐ 动作骨架** | 每张的身体支撑点、手部任务、表情都不同 | **把动作那句抄出来去重**，重复率 > 1/3 就是病 |
| **⭐⭐ 机位** | 平视 / 俯拍 / 低机位 / 门框窥视 / 缝隙视角 / 自拍感 / 远距离抓拍 | 全是平视 = 病 |

⛔⛔ **后两个轴是 2026-08-30 补的，它们是同质化最直接的来源，而且最好查。**
实拍：一批 12 条里**动作有 10 条是同一句「转过头看向镜头，眼神很稳」、机位 12 条全平视**，
那批挑中 1/12；换成动作和机位逐条不同的一批，挑中 6/12。
⭐ 这两个轴的好处是**可以脚本化去重**，不用靠眼睛判 —— 把 `动作` 和 `机位` 两个字段
丢进 `set()` 比长度就行，比其余四个轴都硬。

⛔⛔ **第四个轴是 2026-08-30 补的，因为它被漏掉了整整 35 张。**
前三个轴当时都拉得很开（景别 / 光位 / 场地全部刻意错开），
**但 35 张里主光是冷色的只有 1 张** —— 一组图可以在三个轴上都合格，
读起来仍然是一个味道，因为色温这一维从头到尾没动过。
⭐ 判据简单到可以当场数：**冷主光的张数 / 总张数**，低于 1/4 就是这个病。
病因和修法见第 7 步末尾那条。

⛔ **数值只能证伪不能证真** —— 数值最漂亮那组是「人身上一点光都没有的好看背景板」，
踩过三次。量化指标的用法和五个陷阱见 §9。

⭐⭐ **验收前先抽 3~8 个种子，这条比它看起来重要得多。**
同提示词换种子的摆幅**盖得过整个措辞轴**。最狠的一次实证：同一批 10 条提示词跑两个种子，
**一个种子挑中 7 条，另一个种子 10 条全毙** —— 而两个轴的措辞差异加起来都没这么大。
成品是从约 300 张候选里挑的，**每个位置都换掉了默认那张**。
⛔ **别拿单张判断措辞好坏**，尤其别拿单张去否定一个写法。

## 4. ⭐ 一条定律：名词自带的语义，压得过任何形容词

这条不是某个坑，是**五个坑共同的解释**，也是这份文档里唯一能**预测新情况**的东西。

> **模型先按名词的常识把东西放好，再去读你的形容词。
> 形容词只能微调，推不动名词自带的位置 / 高度 / 数量 / 时间 / 属性。**

| 名词带进来的 | 症状 | ⛔ 压不住的写法 | ✅ 解法：换名词 / 换类别 |
|---|---|---|---|
| **高度**（灯具装在哪）| 顶光，脸压平 | 「路灯，灯头和她的头一样高」| 换**本来就矮**的灯具：矮墙上的马灯 / 台灯 / 灯笼 / 帐篷杆上的营灯 |
| **高度**（招牌装在楼上）| 光源被画到二楼外墙 | 「霓虹灯箱招牌，比她高出一头」| 换**天生齐人高的面光源**：自动贩卖机 / 橱窗灯箱 |
| **数量与排布**（量词）| 光源跑到两侧，边光全没 | 「一**串**红灯笼挂在她身后」| 用**单数**；单数还不够就**给画面里的尺寸**（「占画面高度的四分之一」）|
| **镜头位置**（正前齐脸高）| 光源被挪到身后 / 头顶 | 「一排灯泡在她正前方、和她的脸一样高」| 挪开镜头位，**只有两个安全出口**：**侧前 45°**（方位角）/ **正前偏下**（高度差）。⛔ 别退到「远处的太阳」，那一档已废（§10 ⑭）|
| **时间里有没有太阳**| 太阳没进画，只剩余晖天 | 「**黄昏**的蒲公英坡」| 写「**日落 / 日出**」+ 明写实体：`太阳还没落下去、是一个明晃晃的圆盘` |
| **因果被当成妆容**| 两坨腮红 | 「脸颊被冻得有点红」| 别写「因为 X 所以 Y」，改写**皮肤本身的质地** |

⭐ **怎么用它预测新坑**：写完一句先问自己——
**这句话里的名词，本身带不带位置 / 高度 / 数量 / 时间 / 状态的常识？**
带，而我要的正好和它相反 → **现在就换名词，别指望形容词**。
⛔ 反面教材：为了把太阳拽到头高，我在同一个方向连改四版（换支架三次），
最后发现卡的是「黄昏」两个字 —— 改成「日落」一次就出来了。

## 6. 决策点的判据

### 6.1 深色主体判定 → 光源钉正后方还是偏一侧

**判据：主体朝向镜头的那一面，有没有能透光的东西**（浅色头发 / 薄纱 / 飞起来的碎发 / 浅色衣服）。

- **有** → 光源钉**正后方**，写「照透」。碎发、纱、浅色发会一根根亮起来。
- **没有**（深色发 + 深色衣，或整身黑）→ 光源**偏一侧**，写「擦边」，
  并且**逐条点名**亮线落在哪几条边。钉正后方会被身体整个挡住，出来是剪影。

⚠️ 混合情况（银白头发 + 全黑裙）按**深色**处理：偏一侧 + 逐条点名，头发照样会透。

### 6.2 调不动时：先动构图，还是换概念？

- **改光线句 1~2 次没效果** → 先**动构图**（人的位置 / 景别 / 画幅）。
  ⭐ 构图比光更强：同一套光，人从正脸满框挪到侧脸偏一侧，两项指标一次对上参考片。
- **构图也动了，同一个方向改到第 3 版还没动** → **换概念**（换场景 / 换载体 / 换画幅 / 换角色）。
  卡的是结构性的东西，继续磨措辞是纯浪费。
  ⚠️ 换概念前先过一遍 §4：有时卡的只是一个名词（改「黄昏」为「日落」）。

### 6.3 想要一个禁止项（cfg=1 时）

⛔ 负向提示词形同虚设 → 一律**正向化写成肯定句**，把你要的形状正面描述死。
`没有X` 是在召唤 X。对照表见 §8①。

### 6.4 这张图用哪一个「成像系统」 —— ⛔ 只能有一个

> 📖 折自南鸢写真 skill（§11）。这条我们原来完全没有，但踩过它的坑。

**先选一个主成像系统，再配一两个辅助质感词。**

| 成像系统 | 它具体意味着什么 |
|---|---|
| **CCD / 数码卡片机** | 近距离、硬闪、轻微过曝、真实随拍、现场感 |
| **`direct flash` 机顶直闪** | 皮肤局部过曝、背景快速衰减变暗、眼部高光明显 |
| **`35mm film photography`** | 自然颗粒、轻微色偏、户外抓拍、真实皮肤质感 |
| **VHS / travelogue** | 泛白高光、轻微朦胧、旅行记录感、不过分锐化 |
| **`Pro-Mist` / `bloom` / `film halation`** | 柔雾、高光化开、边缘泛光、旧镜头低对比 |
| **中长焦人像（85 / 105 / 135mm）** | 压缩感、干净的背景分离 |

⭐ **成像系统那一句写在提示词的最前面当定调句**，不要塞在句尾当补充 ——
它要管的是「这张照片是怎么被记录的」，是全局属性，位置靠后会被前面的场景描述盖过去。

#### ⭐⭐ 哪一档能用：挑中率实测（2026-08-29~30，三批 76 张，人工挑片）

原来这张表只说了每档「意味着什么」，**没说哪档能用** —— 这是最大的缺口，现在补上。
判据是**同种子单变量**：光、场景、人物、构图全钉死，只换成像系统那一句。

| 成像系统 | 累计挑中 | 结论 |
|---|---|---|
| **中长焦 85mm 数码** | 5/5 | ⭐ **两个画幅通吃，拿不准就用它** |
| **VHS 录像带** | 6/6 | ⭐ 同上。泛朦低对比反而掩盖了 AI 感 |
| **Pro-Mist 柔雾** | 3/8 | ⚠️ 可用但不是首选 |
| **35mm film / film halation 胶片** | 2/4 | ⚠️ **场景相关**，见下 |
| **CCD 数码卡片机** | 2/10 | ⚠️ 弱档，见下 |
| **机顶直闪** | 1/7 | ⚠️ 最弱的一档 |

⛔⛔ **这张表在 2026-08-30 晚被自己推翻过一次，那个错误比表本身更值得记：**
当天早些时候我按 n=2 的单场景对照写下过「**35mm 胶片整档废掉，别再写**」。
几小时后另一批里 `35mm film` 的果园抓拍和 `film halation` 的旧室逆光**两条都被选中**。
⭐ **真实情况是"胶片在那个场景里输了"，不是"胶片不能用"** ——
那 2 张的病（色偏发脏 + 高光糊脸）是**午后硬光巷子**这个场景放大出来的，
换到树荫漏光和白雾逆光里，同样的「自然颗粒 + 轻微色偏」就是加分项。
⛔⛔ **教训：n=2 的单场景对照只够说"这个组合不行"，永远不够说"这一档不行"。**
一个写死的"整档废掉"比没有结论更糟，因为它会让人再也不去试。

⚠️ **CCD 和直闪是"弱"不是"废"**（2/10 和 1/7）。它们赢的那几张有个共同点：
**场景本身就该有闪光**（夜间办公室的白板、贴脸的夜街快照）。
⛔ 反过来，把 CCD / 直闪套在**本来是自然光的场景**上（花丛、果园、窗边、海边）基本全废 ——
硬闪和场景自带的光在打架，画面会同时读出两套光。

⭐ **由此得一条可用的判据**：
> **先问这个场景在现实里会不会真的有人开闪光灯。** 会（夜店 / 夜街 / 办公室 / 室内快照）→
> CCD / 直闪成立；不会（白天户外 / 窗边 / 花田）→ 换自然光的成像系统。

⚠️ 另一条**还没验的**假设，用之前先自己抽种子：
**成像系统的"强度"要和景别成反比** —— 景别越远越该用干净通透的（数码 85mm），
CCD / 直闪这类重口味的只放近景和特写。⛔ 证据还很薄，别当定论。

⭐ **皮肤档（干净缎光 / 真实纹理）不是这里的变量。** 同一批里两档各 5~6 条，
挑中率 4/5 vs 3/5、4/6 vs 3/6，**两批都没分开** —— 决定成败的是成像系统，不是皮肤写法。
（皮肤本身怎么写仍然重要，见第 6b 步；这里说的只是"选哪一档"这个决定不重要。）

⛔⛔ 南鸢的原话：**「不要把 CCD、VHS、35mm film、商业棚拍、手机自拍和超清质感
同时塞进同一条 prompt。混用会让模型不知道该模拟哪种照片。」**
—— 这正是"每样东西都对但整张就是浑"的一个常见病因，症状见 §5。

⭐⭐ **成像系统固定 ≠ 光固定**（这条最容易搞混）：
成像机制只管"照片如何被记录"，不是把同一盏灯复制到整组图。
一组可以固定 `CCD / direct flash` 的快照响应、反差和颜色，
但**每张的方向、强度、落点、高光宽度和皮肤反射必须随景别和动作重新设计**：
全身环境照可以保留较强的主体分离，**面部近景要降低闪光强度或缩小高光区域**，
不能继续用那套覆盖额头鼻梁双颊的强反光。这和我们 §1 第 2 步
「逆光只镶边不打脸」、第 6b 步的分景别反射是同一族规则。

⭐ 顺带一条判据：**风格要写成可观察的成像机制**，不用"高级 / 氛围感 / 电影感"
代替**白平衡、曝光、反差、高光、锐度、噪点、压缩、景深**。
成像机制至少要回答这 8 个问题，回答不了就是还没想清楚。

### 6.5 光源钉在世界坐标里 —— 换机位不带着光一起转

> 📖 折自南鸢写真 skill 的 `references/production-reshoot.md`（§11）。

**同一场景换机位 / 换动作时，最容易犯的错是让光跟着相机转。**
固定规则：**机位变化不能带着光源一起旋转。**
先把光源、遮挡物（屋檐 / 窗洞 / 伞面 / 竹叶 / 树枝）、墙地和环境回填
**放在世界坐标里**，相机只改变观看位置；动作改完之后**再重新判断**
哪些表面能看见光、被什么挡住、把什么颜色反射回来。

五层最小记录：**光源 → 遮挡与调制 → 人物落点 → 环境落点与反射 → 曝光结果**。

三条最常见的矛盾（出现即回到 §1 第 3 步）：
- 大面积阴天散射或柔和窗光，**不能无故变成**狭窄硬边光、强轮廓光或舞台顶光。
- 俯拍只改变相机位置，**不能**把侧窗 / 门洞 / 水平环境光改成从镜头上方直射的暖顶光。
- 新动作或新道具挡住了原主光，**必须接受对应的阴影**，或者挪人的位置；
  不能同时要求"挡光"和"脸上落点完全不变"。

⛔ 写法纪律：**先写正向的物理关系，再补 1~3 个具体禁止项。**
只写"保持相同光影""复制参考图光线"或者堆一串禁止词是没用的
—— 这些句子没有说明新机位下光**为什么**落在那里。

## 7. 附录 A：各族与各档的写法细则

### 7.1 特写族

三件套：① 相机句写死画框（第 1 步）；② 一个**贴脸**的光源（身后一点点的钠灯 / 头顶的伞面 /
她手里的发光小物件）；③ **打脸四件套里的「暗面」那一件**（第 2 步）。

⭐ 第三条是"好看"的开关，不是修辞。明亮的正面光会把脸的所有缺陷平铺出来；
被暗部托着、只有轮廓和高光是亮的，同一张脸立刻上一个台阶。
⛔ 但它**只能和亮面一起出现**，别单独写成「脸的其余部分落在柔和的暗部里」——
那是全暗脸的写法，废过 38 张。四件套原文在第 2 步，照抄那一段就对了。

⭐ **特写只能竖幅这条现在有第二类证据**：仓库 `assets/` 里所有 16:9 素材**一张特写都没有** ——
不是没排，是那个画幅里排不出来（12 张实证在上一段）。要特写就换竖幅，别在 16:9 里磨措辞。

⛔ **特写只能用竖幅**（实证）：同一句特写相机放进 16:9，连改三版
（放大相机句 → 上装只写领口 → 把光压到日落后）**十二张出图景别一寸没动**、脸始终只占 1/5；
换成竖幅一次到位。16:9 的画框本身在要求横向填充，人只占半边时模型会把另一半补成环境。

### 7.2 近景 / 半身族

⛔⛔ **下面两条是「镶边光」的句式，不是主光方案 —— 只能当第二个光源用。**
早期版本把它们写成「光的写法二选一，都验过 6/6」，那个 6/6 量的是
"发丝有没有一根根亮起来"，**不是"人好不好看"**；后来第 2 步实测
只有镶边的那一组八张全毙。两件事，别再当成一件。

- **侧脸发丝**：`光从她耳后斜穿过头发，把外圈那些飞起来的碎发一根一根照透、亮成细细的暖橘色亮线，脸颊外缘留下一条细亮边。`
- **正脸环光**：`光源在她正后方、和她的头一样高，整个头的外圈镶上一整圈细细的暖橘色发丝亮线，两边脸颊外缘各留下一条细亮边。`
  ⭐ 正脸一样能有整圈发丝光，不用非把脸侧过去。
  ⚠️ 这里的「和她的头一样高」之所以能写，是因为它钉的是**正后方**的逆光；
  **主光绝不能这么写**（第 3 步②）。

⭐ 正确用法：**镶边归镶边，脸归脸，两个光源分开写。**
⚠️ 但也别反过来强求 —— 按 §0.5，如果这张的成立点是场景或成像方式，
**发丝镶边这一层完全可以不写**。实拍挑中率最高的那几张里就有一张镶边都没有。

背景是流动的虚化色块 + 一句介质。⭐ 颜色不限：绿 / 粉 / 金 / 霓虹 / 冷白全成立，别一律刷暖金。

### 7.3 环境人像族

⛔ 最容易退化成「风景很美、人身上一点光都没有」的好看背景板。
防线只有一条：**风景可以铺满，但主光源必须留在她身边**。
远处的城市灯火、云海、山谷灯火**只能当第二层**（补色的那一半），不能当主光。

⚠️ 这一族**过了防线也常常只是"不废"**，离"好看"还差整个 §2 —— 横幅里人天然小，
撑场面的必须是那片会发光的介质和那条几何线，不能只靠人身上一圈边光。
⭐ 这一族的介质**吃画幅**：特写里够用的萤火虫 / 细尘，放进横幅就撑不起 2/3 的风景
（→ §7.4），要换成整片的花穗 / 落叶 / 雪 / 火星 / 水花 / 光柱。

### 7.4 自发光档（最极端的冷调路子）

⚠️ 早期版本这里写的是「**唯一**的冷调路子」，已经不对了 ——
第 7 步那张表里的霓虹 / 屏光 / 蓝紫射灯 / 月光雪地都是冷主光，只是没这一档极端。
**自发光档的特别之处不是"冷"，是"全图只有一个很小的光源，人整个压在暗部"。**

⚠️⚠️ **这一族是第 2 步「必须打脸光」的唯一例外，而且是有代价的例外**：
它明确不追求「人美」，追求的是氛围和冷调。想要人好看就别走这一档，走完就别怪脸不立体。

⛔ 和逆光**方向相反**，不是它的一个场景。三条内核：
① 全图唯一的主光是她手里 / 身边那个**自己会发光的小东西**；
② 人整个压在暗部，脸比那个光源暗好几档；
③ 冷调低饱和，**全画面只有那个光源是另一个颜色**。

- ⛔ **改暖调直接废**（冷是命根子）；⛔ **去掉那个发光物直接废**（它是唯一主光）。
- ⭐ 内核和道具无关，**换载体照样成立**：粉百合 → 掌心萤火虫 → 帐篷杆上的营灯 → 篝火，
  三条一条没改，画面完全是新的。**先拆这三条再挑载体，别照抄道具。**
- ⚠️ **载体亮度要配得上画幅**：萤火虫在特写里够用，放进横幅环境人像里光量撑不起
  2/3 的风景，整张发闷发空 —— 换营灯 / 提灯 / 篝火。

## 8. 附录 B：⚠️ 模型相关 —— 换模型要重新验

**① cfg=1 时负向提示词形同虚设。**
适用于所有开了 Lightning / turbo / 蒸馏加速的模型。填了不报错，只是不生效。

| 想要 | ⛔ 写不出来 | ✅ 正着写 |
|---|---|---|
| 不要投影 | negative: `shadow` | 「每个物体都直接贴在白纸上，不产生任何投影」 |
| 脸别太圆 | 「脸不胖」 | 「窄长的鹅蛋小脸，脸颊平顺内收、下颌角收窄，下巴是尖的」 |
| 皮肤干净 | 「无瑕 / 没有痘」 | 「脸颊、下巴和嘴角是连续平整的一片皮肤」 |
| 短裙别变连体衣 | 「不是连体衣」 | 「裙筒是完整闭合的一圈、四周一样齐地把大腿包住」 |
| 丝袜不透明 | 「不透明的丝袜」 | 换名词：「天鹅绒打底裤袜」 |
| 眼里的反光**两只对称** | 「眼睛里有**一颗**清楚的反光点」 | 「**两只眼睛里各有一小点一样大小、一样位置的**暖橘色反光」 |
| 眯眼**两只一起眯** | 「她微微**眯起眼**看向镜头」 | 「她**两只眼睛一起**微微眯着、**两边的眼缝一样窄**」 |
| **故意**只闭一只（wink）| 「她冲镜头 wink」 | 「她**只闭上左边那只**眼睛、**右边那只睁得很大**地看向镜头」 |

⭐⭐ **最后那一行是这条规则的正面用法，别把 wink 当禁区。**
病因从来不是"不能只闭一只眼"，是**没钉数量和对称就随机挑一只**。
钉死是哪一只之后，wink 就是个稳定可控的表情（实拍验过）——
这也让本文件和外部写真 skill 的冲突消解了：它把 wink 列进活泼表情池是对的，
只是它没写"要钉死哪一只"。

⚠️ 眼睛那条是 2026-08-29 实拍验出来的，代价是两批 80 张：**「一颗」是数量信息，模型照做** ——
只在**一只**眼里点一个又大又实的光斑，两眼不对称，一眼假。写法上要同时做两件事：
**把数量正着钉成「两只眼睛各一点」**，并把「一颗清楚的反光点」**降级成「一小点」**（缩小体积）。

⚠️⚠️ 2026-08-30 又栽了一次，**同一个病换了个壳**：写「微微眯起眼」，出来是
**一只眼闭着的 wink**（3 张写了这三个字的图 3/3 全中，没写的两张双眼正常）。
⭐ 归纳成一条通则：**任何作用在成对器官上的状态词，不钉数量和对称就默认只作用在一只上。**
眼睛是最容易踩的（反光、眯、眨、挑眉都算），因为 wink / 单眼反光在训练数据里本身就是常见画面。
⛔ 附带伤害：那 3 张**同时长了腮红**。原文都带因果从句（「被光晃得」「被晒得睁不开」「像在忍住笑」）
—— 晒 / 羞 / 忍笑自带脸红先验，cfg=1 下负向压不住，**只能整句不写**，改成中性表情。

规律叫「**可选结构改成不可选**」。⚠️ cfg 提到 4 以上负向才真正生效，代价是步数和时间。
⚠️ 注意区分：这条是**负向框不生效**；§4 那条是**正向里名词压过形容词**。两条都要守。

**② 字数预算是控景别的主变量，比相机句强。**
⭐ **景别靠画框内的身体 / 服装内容撑出来** —— 写了哪个部位，就等于把画框拉到哪个部位。
实测：中景写「裙摆垂到小腿」画框滑成全身；特写写「她穿着开衫」立刻退回胸像。
⚠️⚠️ **字数带宽不是一个数，是按「画幅 × 挂不挂 LoRA」分档的**，
早先版本把两档并排写成一句，看起来像自相矛盾。实测过的四档：

| 档 | 带宽 | 备注 |
|---|---|---|
| 竖幅 + 角色 LoRA | 近景 405~448 / 中景 468~510 | 最窄的一档，超一点就滑 |
| 竖幅，不挂 LoRA | 533~593 | 特写 / 近景 / 半身 12 条全部守住 |
| 16:9 横幅，不挂 LoRA | 475~656 | 近景 / 半身 / 中景 12 条全部守住 |
| 竖幅，模块化模板（【穿搭】【场景】…）| ~1240 | 模板本身占掉一半字数，不能和上面几档比 |

⭐ 规律是**带宽随画幅和模板变，但「长度是主变量」这条通用**。换模型 / 换模板要重新标定。

⭐ **还原度优先于字数上限**：削长度时从戏服末尾砍分句，砍掉的正好是还原度最吃重的名词
（盘扣、腰带流苏、白长手套、羽毛状裁片）。上限该重标就重标，别让它吃掉戏服。

⛔⛔ **如果你的流程里有「超上限就自动砍最后一个分句」这种代码，它会静默吃掉服装。**
2026-08-30 实拍中招两处：一套的中景丢了整件连帽外套、另一套丢了银色颈链 ——
而**同一套的其余几刀都有**。单看那一张挑不出毛病，**剪进同一组才看得出衣服变了**，
而且下一刀的动作（「把外套肩头往回拉」）正好在演一件不存在的衣服。
⭐ 判据只能看**最终拼出来的那条提示词**，看源字段一个都发现不了。

**③ 景别没守住时，画框外的字段会被模型自己编出来。**
⭐ 修法**不是加字数，是换景别**：改走本来就要写那个部位的景别，再用肯定句写死它。

**④ 同提示词同 seed 未必可复现**（这套 ComfyUI 下平均像素差 29/255）。
任何改法先过噪声底，别把噪声当成措辞的效果。

**⑤ 同一个人在同一组里，脸的那句必须一字不差地复用。** 做成同一个字符串常量。

**⑥ 挂角色 LoRA 时，「景别槽」同时决定戏服写多少 —— 别为了脸大就选最近的那档。**
⚠️ 字段名和模板绑定，但**"最近的景别档往往没有完整服装字段"这个坑是通用的**：
这套 cos 模板里近景档走 `基底近 + 领`（**没有上装字段**），戏服还原度直接掉一大截。
⭐ 要「脸大 + 戏服完整」，正解是**半身档**：有完整上装、不写腿 → 画框自然收到腰。

**⑦ ⛔⛔ 腮红：措辞只能清掉约 7/10，剩下的 3/10 靠排片，不要再磨措辞。**
（本机 z-image turbo 上 **7 臂 × 3 主题 × 2 种子 = 42 张**归因实测。
判据是**皮肤像素里 R−G 的「上 5% 比中位高多少」**，越小越干净；
⚠️ 肉眼在缩略图上判不准，我判错过一次。）

先做这两件**有效**的：
1. **正向化写脸颊肤色**（§6.3 的公式：先正面说这块皮肤是什么，再列否定）：
   > 两边脸颊和鼻梁是和额头、下巴连续的同一片自然肤色，没有腮红、没有额外的红晕或色块。
2. **换掉自带腮红先验的妆容名词**（§4 的定律）：`桃粉甜美妆` / `玫瑰水光妆` /
   `青苹果氧气妆` / `Y2K 桃粉玻璃唇妆` / `冷欲猫系妆` 这类**名字本身就在召唤腮红**，
   一律换成「很淡的裸妆」。

然后**停手**。以下四个方向全部实测无效或更差：

| 臂 | 红斑强度 | 结论 |
|---|---|---|
| C 冷光（只换色温） | **18.3** | 唯一有效，但只对落日逆光那组，窗光那组反而更糟，且暖氛围一起没了 |
| **W 现状（上面那两条）** | **19.7** | **已是措辞层面最优，别动** |
| M 把「妆 / 底妆」整个删掉 | 19.7 | 完全无效 |

## 9. 附录 C：量化指标 —— ⛔ 只能证伪，不能证真

口径（实现在 `docs/对照实验.md`）：P1 = 最暗 1% 分位亮度；CLIP = 过曝像素占比；
dB = 暖冷分离；HALO = 光晕；LAP = 锐度方差；BGFG = 边缘锐度 / 中心锐度。

⛔ 五条**别当及格线**：

- **CLIP 不是及格线**。曾定过「甜区 0.5~2%」，10 张成品里 8 张 CLIP<0.5、肉眼全部有发丝透光，
  反而超上限那张是唯一光糊掉的。它只能抓「光源盘被拽进画面」那种爆掉的（>3%）。
- **dB 只对有冷环境光的场景有意义**。海边 / 雪原 / 樱花 dB 是负的，画面并不差。
- **HALO 在高光像素太少时直接返回 0**（光源出画必为 0），别读成「没有光晕」。
- **LAP 不能跨场景比**。夜景天然高（雨后夜街 386，白天档 29~110）。
- **P1 不能跨构图族比**。满画面逆光的 P1 天然 20~50，近景那条 P1≈15 套到全身上全是误判。

## 10. 附录 D：实验依据

流程里的每一步都来自一组只改一句话的 A/B，这里是出处，供不信的人复核。

**① 光靠场景写，不靠形容词。** 光线形容词堆句尾、五档强度递进，三项指标**纹丝不动**；
场景句从「身后是干净的暖白色墙面」换成「身后是敞开的店门和门外的街道」，
逆光一次就出来（暗部抬升 7→12、过曝 0.2%→3.8%）。原因：**墙把光源挡在画框外了**。

**② 空气必须有介质。** 只写「金色时刻」暖冷分离 = −10.11；加「空气里浮着被照亮的细小尘埃」→ +1.37。

**③ 不许单独写「暗部是冷的」。** 模型会把整张图一起吹冷（暖冷分离掉到 −1.04）。
暖冷分离只能靠**场景自带两个色温的光源**。

**④ 柔焦类提示词零效果。** 五档柔焦写法实测锐度不降反升（LAP 275→318），肉眼五张无差。
要柔只有两条路：加雾（晨雾把 LAP 96 压到 55），或放后期做 bloom。

**⑤ 构图比光更强。** 同一套光，人从正脸满框挪成侧脸偏一侧，
两项指标一次对上参考片（LAP 96→24.5、BGFG 0.48→3.36）。

**⑥ 补色对是「抓不抓眼球」的直接来源。** 把成品和被淘汰的那批并排比，
最强的信号不是光有多准，是**画面里有没有两个对立的色温**。

**⑦ 光源离主体远 = 零轮廓光。** 「整片城市霓虹就在她身后」（几百米外）出来是背景板；
「太阳卡在她身后两棵树的树干之间」（树太远）同病。

**⑧ 支架必须有缝、比她高、离得近。** 光秃秃的海平线和开阔天空五种措辞出图几乎一模一样；
身后一整面墙 / 门 / 一排橱窗，36 张里 10 张栽在这上面。
齐腰的鼠尾草和齐胸的芒草托不住太阳（2 张实证），换成孤松 / 风车立刻成立。

**⑨ 逆光只镶边不打脸 = 人不美。** 一组十张里八张边光 / 贴身光源 / 补色全成立、
主光全在后方，八张全毙；改成侧前 45°、正前偏下、远处正前方三种打脸光后全部翻身。

**⑩ 背景「碎 vs 大」是选中与被毙之间唯一 100% 分得开的变量。**
选中的背景全是大块 + 一条几何线；被毙的全是细碎堆叠且一条线都没有。

**⑪ 名词自带的语义压过形容词。** 五个独立实例（灯具高度 / 招牌高度 / 量词 / 镜头位 / 时间词），
每个都是"形容词连改数版无效、换名词一次成立"。见 §4。

**⑫ 成像系统是独立于光的第三个轴，而且有的档整档不能用。**
2026-08-29~30 三批 76 张，光 / 场景 / 人物 / 构图全钉死只换成像系统那一句：
四批累计：数码 85mm 5/5、VHS 6/6、柔雾 3/8、胶片 2/4、CCD 2/10、直闪 1/7。
同一批里皮肤档（干净缎光 vs 真实纹理）两档挑中率没分开 —— **选哪一档不重要，
成像系统选错才致命**。⚠️ 但强弱**不等于**能用不能用，⛔ 弱档输在哪要看场景（见 ⑰ 和 §6.4）。

**⑬ 换种子的摆幅盖得过整个措辞轴。** 同一批 10 条提示词、两个种子：一个 7/10，另一个 0/10。
见 §3。

**⑯ 「把每条判据都套在每一张上」会亲手做出同质化，代价是 6 倍挑中率。**
四批 48 条实拍：全套骨架无差别套用的两批 **1/12、1/12**；
改成每条先定一个「成立点」、其余允许留白的那批 **6/12**。
可量化的病灶是**动作骨架和机位**：前者 12 条里 10 条同一句、后者 12 条全平视。
⭐ 这两个轴能脚本化去重，是所有组级判据里最硬的。见 §0.5 和 §3。

**⑰ 「整档废掉」这种结论不能从 n=2 得出。** 同一天先按单场景 2 张写下
「35mm 胶片整档废掉」，几小时后另一批里胶片的果园和旧室两条都被选中。
⭐ 正确的说法是「这个组合在这个场景里不行」。见 §6.4。

**⑮ 主光色温是组级的第四个轴，而且是最容易整批漏掉的一个。**
2026-08-30 盘点：35 张成品素材在景别 / 光位 / 场地三个轴上都刻意错开了，
**主光是冷色的却只有 1 张**。三个轴全合格，一组读起来仍然是一个味道。
根因不在写法，在**参考的那份风格清单本身就没有冷光入口**（见 §11.1）——
⭐ 由此得一条通用的：**抄别人的清单前，先把它按维度列成表看哪一列是空的。**

**⑭ 「远处的正前方太阳」这个光位整档不成立。** 3 条实拍 3/3 退化成真逆光（脸崩 + 单眼闪光）。
病因：它没有第三个可钉的维度，高度只能靠形容词「压得很低」撑，而形容词压不过
「正前方」这个名词自带的镜头位（⑪ 的又一个实例）。见第 3 步②。
