# 人像光线配方

> **这是方法论，不是某个模型的参数表。** §1~§4 是构图和光学层面的规律，换模型照样成立；
> §5 才是和采样器 / 条件机制绑定的，换模型要重新验。
>
> 证据来自 z-image（本地 ComfyUI）上十五轮 ~120 张**同种子单变量**对照，
> 加三轮成品重做 ~90 张。每条结论都对应一组只改一句话的 A/B，
> 逐轮数据在 `docs/对照实验.md`，十张成品的完整提示词在 `docs/配方全文.md`。
> 提示词全部是**纯中文整段**，粘到豆包 / 即梦 / 通义 / Midjourney 的中文入口同样成立，
> 不用拆词、不用配负向。

## 0. 动手前先回答三个问题

写任何一条人像光线提示词，顺序永远是这三步，**跳过哪一步就废在哪一步**：

1. **光从哪来？** —— 场景里哪个具体的东西在发光（太阳 / 火 / 霓虹 / 马灯 / 她手里的小玩意）。
2. **它离她多近、在她的哪个方位？** —— 距离和方位都要钉，见 §3。
3. **画面是什么构图族？** —— 特写 / 近景 / 环境人像，三族的写法互相矛盾，见 §2。

答不上第 1 问就直接去堆「唯美的逆光」「电影感光影」，是这件事上最常见也最贵的错。

## 1. 六条通用规律（换模型也成立）

**① ⛔ 光是靠场景写出来的，不是靠形容词。** 最贵的一条。
光线描述堆在句尾、五档强度递进，三项指标**纹丝不动**，肉眼也无差；
把场景句从「身后是干净的暖白色墙面」换成「身后是敞开的店门和门外的街道」，
逆光一次就出来（暗部抬升 7→12、过曝 0.2%→3.8%）。

原因很朴素：**墙把光源挡在画框外了**。模型不是不听「逆光」，它是按你描述的场景推物理。
所以正确姿势不是形容光，是**把场景写成物理上只可能这么打光**。

**② ⛔ 空气里必须有被照亮的东西**（尘 / 絮 / 花瓣 / 水雾 / 雪粒 / 火星 / 干冰烟 / 细雨丝）。
只写「金色时刻」，暖冷分离 = **−10.11**（负的，等于没有）；
加一句「空气里浮着被照亮的细小尘埃」→ **+1.37**。
**没有介质，光就只是背景亮，不成氛围。** 介质是什么无所谓，跟着场景走。

**③ ⛔ 不许单独写「暗部是冷的」。** 模型不会只冷暗部，它把整张图一起吹冷
（暖冷分离反而掉到 −1.04）。暖冷分离只能靠**场景自带两个色温的光源**——
树林的暖光柱配冷绿树荫、蓝调时刻的冷天配暖橘窗灯。

**④ ⛔ 柔焦类提示词零效果。** 五档柔焦写法实测锐度不降反升（LAP 275→318），肉眼五张无差。
要柔只有两条路：**加雾**（晨雾把 LAP 96 压到 55），或者**放到后期做 bloom**。

**⑤ ⭐ 构图比光更强。** 同一套光，把人从正脸满框挪成侧脸偏一侧，
两项指标一次对上参考片（LAP 96→24.5、BGFG 0.48→3.36）。
模型是听得懂「她站在画面右边三分之一处」的 —— 光调不动的时候，先动构图。

**⑥ ⭐ 每张给一组补色对，这是「抓不抓眼球」的直接来源。**
把十张成品和被淘汰的那批放一起比，最强的信号不是光有多准，是**画面里有没有两个对立的色温**：
暖橘钠灯 ↔ 冷蓝雪夜、火橘 ↔ 夜蓝、蓝紫射灯 ↔ 暖橘荧光棒、冷蓝银河 ↔ 暖黄营灯。
单一色调铺满一张（全暖褐的书店、全青蓝的夜街）不管光多对，看上去都是平的。
⭐ 写法：**主光定一个色温，场景里再找一个反色温的第二光源**，
夜景尤其好办（青蓝霓虹里塞一块暖橘灯牌，蓝紫舞台外补一盏暖橘侧灯）。

## 2. 三种构图族 —— 规律互相矛盾，先选族再写

| | 特写 | 近景 / 半身 | 环境人像（横幅）|
|---|---|---|---|
| 画面里是什么 | 只有脸和光 | 人 + 一片糊掉的背景 | 人占 1/3，风景占 2/3 |
| 靠什么成立 | **暗部托脸** + 一个贴脸的光源 | **构图**（人偏一侧 + 背景全糊）| **场景几何** + 贴身主光 |
| 背景 | 正向写死「糊成一片没有细节」 | 同左 | **反过来：要有细节**，摘掉「浅景深」|
| 最容易废在 | 画框收不住，退成胸像 | 背景抢戏 | 退化成「好看的背景板」|
| 画幅 | ⛔ **只能竖幅** | 竖幅横幅都行 | ⛔ **只能横幅** |

### 2.1 特写族

三件套：① 相机句写死「额头顶到画框上沿、下巴落在画面正中、两边脸颊快碰到画框左右」；
② 一个**贴脸**的光源（身后一点点的钠灯 / 头顶的伞面 / 她手里的发光小物件）；
③ 正向补一句「**脸的其余部分落在柔和的暗部里**」。

⭐ 第三条是"好看"的开关，不是修辞。明亮的正面光会把脸的所有缺陷平铺出来；
被暗部托着、只有轮廓和高光是亮的，同一张脸立刻上一个台阶。

⛔ **特写只能用竖幅。** 同一句特写相机放进 16:9，连改三版（放大相机句 → 上装只写领口 →
把光压到日落后）**十二张出图景别一寸没动**、脸始终只占 1/5；换成竖幅一次到位。
16:9 的画框本身就在要求横向填充，人只占半边时模型会自动把另一半补成环境，等于把景别拉远。

### 2.2 近景 / 半身族

1. **人在画面一侧**、从胸口（或腰）往上入镜，另一侧一大片虚化背景。
2. 光的写法二选一：
   - **侧脸发丝**：「光从她耳后斜穿过头发，把外圈那些飞起来的碎发一根一根照透、亮成细细的暖橘色亮线，脸颊外缘留下一条细亮边。」
   - **正脸环光**：「光源在她正后方、和她的头一样高，整个头的外圈镶上一整圈细细的暖橘色发丝亮线，两边脸颊外缘各留下一条细亮边。」
     （⭐ 正脸一样能有整圈发丝光，不用非把脸侧过去。）
3. 背景是流动的虚化色块 + 一句被照亮的介质。⭐ 颜色不限：绿 / 粉 / 金 / 霓虹 / 冷白全成立。

### 2.3 环境人像族（横幅）

相机句：「一张 16:9 横幅的真实照片。她站在画面右边三分之一处、从膝盖往上入镜，
身高占满画面高度的三分之二，左边三分之二整个让给风景。」

⛔ **这一族最容易退化成「风景很美、人身上一点光都没有」的好看背景板。**
防线只有一条：**风景可以铺满，但主光源必须留在她身边**——
身后半米的火盆、与肩同高的霓虹、卡在她身后两丛芦苇之间的落日。
远处的城市灯火、云海、山谷灯火**只能当第二层**（补色的那一半），不能当主光。

配套两条：
- ⛔ 质感句里的「浅景深」要摘掉 —— 这一族要的正是背景有细节。
- 风景本身也要写光：**「日出」只交代时间，不交代天空长什么样**。
  实测只写「日出的白花田」出来的是大白天；得把天空画出来：
  「太阳只露出一半、天边是浓的橘红色、天顶还是没褪干净的深蓝色」。

## 3. 光源怎么钉 —— 三个维度，缺一个就飘

**① 距离：⛔ 光源离主体远 = 零轮廓光，措辞再对也救不回来。**
「夜晚天台的边缘，整片城市霓虹就在她身后」——霓虹在几百米外，落到人身上的光约等于零，
模型改从正面补光。同一条也砸过「太阳卡在她身后两棵树的树干之间」（树太远）。
⭐ 判据换成**光源离她有多近**：齐腰的花枝之间 / 身后半米的火盆 / 挂在她身边帐篷杆上的营灯。

**② 方位：只钉高度不够，方位也要钉死。**
「和她的头一样高」只锁了高度，太阳照样会飘到侧后方去，轮廓光只剩一点。
补一句「**正好在她的头的正后方**」，一次归位。两句要一起写：
「太阳正好在她的头的正后方、从两根松枝之间跳出来、和她的头一样高、正对着镜头」。

⚠️ **例外：深色主体要的是擦边光，不是正后方光。**
上面这条的前提是主体能透光（浅色头发、薄纱、飞起来的碎发）。
一身黑的角色把光源钉在**正**后方，光被身体整个挡住 —— 出来是**剪影，不是边光**。
改法两步：光源**偏一侧一点**，再把亮线落在哪几条边上**逐条点名**：
「把她银白色头发的外圈、右边肩膀的边缘和右臂的外侧各照出一条清晰的暖金色亮线」。

**②b 量词也是位置信息。**
写「一**串**红灯笼挂在她身后」，模型理解成街道两边成排的灯笼，光源等于跑到两侧去了，边光全没。
⭐ **要一个定点光源就用单数**：「一盏很大的红灯笼就挂在她正后方半米」。

**③ 灯具名词自带高度，⛔ 别指望形容词把它拽下来。**
写「一盏路灯，灯头和她的头一样高」，模型按路灯的常识把灯架到她**正上方**，出来是顶光、脸压平。
⭐ 要低位光源就换一个**本来就矮**的灯具：老式马灯放在矮墙上 / 台灯 / 灯箱 / 帐篷杆上的营灯。
同理「成排射灯」自带天花板语义，得先把距离钉死在「身后一米」才压得住。

**④ 「身后那个高的东西」是逆光的支架。**
光源要架到头肩高度，靠场景里一个高的东西把它托起来：
树干之间 / 两栋楼的缝 / 巷口 / 门洞 / 灯杆 / 棚架立柱 / 两片晾晒的床单之间。
⛔ **光秃秃的海平线和开阔天空写什么都没用** —— 五种措辞出图几乎一模一样。
⛔ **身后不能是一整面墙 / 一扇门 / 一排橱窗**（36 张里 10 张栽这上面）：
墙把光源挡在画框外，全退化成平光。修法是站到**缺口正中**；
「场景全部内容就是一整面平面」的直接换地点，别硬凑。

**⑤ 背景要写「被照透」，不能写「逆着光的 X」。**
「整片背景被这个光源从背后照透成发亮的暖金色」✅；
「身后是逆着光的树丛」会被画成实体暗块，一个光斑都不出。

**⑥ 光斑落点要正向限定**：「金色光斑全部落在她身后很远的虚化背景里」——
不限定它会飘到脸上变成一颗橘色圆饼。

**⑦ 夜景照做，把太阳换成灯**：她身后头肩高度的路灯 / 壁灯 / 霓虹 / 灯箱 / 火盆 / 射灯，
上面六条一字不改。⭐ 舞台是所有夜场里最好写的 —— 射灯位置和干冰烟两条硬要求，场景自带。

## 4. 自发光档（唯一的冷调路子）

⛔ 和逆光**方向相反**，不是它的一个场景。三条内核：
① 全图唯一的主光是她手里 / 身边那个**自己会发光的小东西**；
② 人整个压在暗部，脸比那个光源暗好几档；
③ 冷调低饱和，**全画面只有那个光源是另一个颜色**。

- ⛔ **改暖调直接废**：冷是命根子，不是风格偏好。⛔ **去掉那个发光物直接废**：它是唯一主光。
- ⭐ 内核和具体道具无关，**换载体照样成立**：粉百合 → 掌心萤火虫 → 帐篷杆上的营灯，
  三条一条没改，画面完全是新的。**用这一档时先拆出这三条再自己挑载体，别照抄道具。**
- ⚠️ **载体的亮度要配得上画幅**：萤火虫在特写里够用，放进横幅环境人像里
  **光量撑不起 2/3 的风景**，整张发闷发空，必须换个亮得多的载体（营灯 / 提灯 / 篝火）。

## 5. ⚠️ 模型相关 —— 换模型要重新验的部分

**① cfg=1 时负向提示词形同虚设，禁止项必须正向化。**
适用于所有开了 Lightning / turbo / 蒸馏加速的模型（z-image、Qwen 换装、S2V…）。
往负向框里填不报错，只是不生效 —— 最容易误判成「模型不听话」。

| 想要 | ⛔ 写不出来 | ✅ 正着写 |
|---|---|---|
| 不要投影 | negative: `shadow` | 「每个物体都直接贴在白纸上，不产生任何投影」 |
| 脸别太圆 | 「脸不胖」 | 「窄长的鹅蛋小脸，脸颊平顺内收、下颌角收窄，下巴是尖的」 |
| 皮肤干净 | 「无瑕 / 没有痘」 | 「脸颊、下巴和嘴角是连续平整的一片皮肤」 |
| 短裙别变连体衣 | 「不是连体衣」 | 「裙筒是完整闭合的一圈、四周一样齐地把大腿包住」 |
| 丝袜不透明 | 「不透明的丝袜」 | 换名词：「天鹅绒打底裤袜」 |

规律叫「**可选结构改成不可选**」：`没有X` 是在召唤 X，
唯一有效的办法是把你要的那个形状**正面描述死**。
⚠️ cfg 提到 4 以上（关掉 Lightning）负向才真正生效，代价是步数和时间。

**② 字数预算是控景别的主变量，比相机句强。**
⭐ **景别是靠画框内的身体 / 服装内容撑出来的** —— 写了哪个部位，就等于把画框拉到哪个部位。
实测：中景档写「裙摆垂到小腿」，画框直接滑成全身；特写档写「她穿着开衫」，立刻退回胸像。
所以两件事同时做：① 按景别选字段（**特写只写到领口为止**、近景写领口、半身写上装、
中景写下装+腿、全身写鞋+地面）；② 卡字数上限。
⚠️ 具体的字数区间是模型相关的（这套 z-image + LoRA 上是近景 405~448 / 中景 468~510），
换模型要重新标定，但「长度是主变量」这条本身通用。

**③ ⛔ 景别没守住时，画框外的字段会被模型自己编出来。**
半身档按规矩不写下装（在画框外），前提是画框真的切在腰上；提示词一长画框滑到膝盖，
下半身进了画面而提示词里一个字都没有，模型就自由发挥。
⭐ 修法**不是加字数，是换景别**：改走中景（中景本来就要写下装），再用肯定句写死它。

**④ ⛔ 同提示词同 seed 未必可复现。** 这套 ComfyUI 下平均像素差 29/255。
任何改法先过噪声底，别把噪声当成措辞的效果。

**⑤ ⭐ 同一个人在同一组里，脸的那句必须一字不差地复用。**
各景别各写一句「差不多的脸」= 跨景别长相飘。做成同一个字符串常量。

## 6. 验收 —— ⛔ 数值只能证伪，不能证真

可以量的（实现在 `docs/对照实验.md`）：P1 = 最暗 1% 分位亮度；CLIP = 过曝像素占比；
dB = 暖冷分离；HALO = 光晕；LAP = 锐度方差；BGFG = 边缘锐度 / 中心锐度。

⛔ 五条**别当及格线**：
- **CLIP 不是及格线**。曾定过「甜区 0.5~2%」，10 张成品里 8 张 CLIP<0.5、肉眼全部有发丝透光，
  反而超上限那张是唯一光糊掉的。它只能抓「光源盘被拽进画面」那种爆掉的（>3%）。
- **dB 只对有冷环境光的场景有意义**。海边 / 雪原 / 樱花 dB 是负的，画面并不差。
- **HALO 在高光像素太少时直接返回 0**（光源出画必为 0），别读成「没有光晕」。
- **LAP 不能跨场景比**。夜景天然高（雨后夜街 386，白天档 29~110）。
- **P1 不能跨构图族比**。满画面逆光的 P1 天然 20~50，近景那条 P1≈15 套到全身上全是误判。

⚠️ **数值全对也可能是废片** —— 数值最漂亮那组人身上一点光都没有，就是个好看的背景板。
这条踩过三次。**唯一可靠的验收是肉眼看：发丝有没有一根根亮起来、人身上有没有轮廓光。**

## 7. 工作方法：挑片 > 改措辞

⭐ **同提示词换种子的摆幅，比绝大多数措辞改动都大。**
一次抽 3 张挑最好的，比反复改提示词有效得多 —— 十张成品是 30 张候选里挑的，
**10 个位置全部换掉了默认那张**。

⭐ **改三版还不动就换概念，别继续磨措辞。**
特写那一位在 16:9 下连改三版、十二张出图纹丝不动；换成竖幅樱花一次到位。
判据很简单：**同一个方向改过三次、指标和肉眼都没动，说明卡的是构图或画幅这类结构性的东西，
不是措辞。**
