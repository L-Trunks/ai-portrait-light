# 人像光线配方

> **这是一套判断流程，不是词表。** 每一步只做一个决定，每个决定都有判据；
> 判不出来就停在那一步，别往下走，也别改措辞去撞。
>
> 证据来自 z-image（本地 ComfyUI）上 ~200 张**同种子单变量**对照，
> 加六轮成品迭代（约 300 张候选，人工挑片，六轮里有四轮是整组推倒）。
> 逐轮数据在 `docs/对照实验.md`，成品的完整提示词在 `docs/配方全文.md`。
> 提示词是**纯中文整段**，粘到豆包 / 即梦 / 通义同样成立，不用拆词、不用配负向。

## 0. 先看这个：这是两道独立的关

```
      要写一条              图已经出来了
          │                      │
          ▼                      ▼
   §1 七步装配 ─────────┐   §5 诊断表（从症状进）
   （第一关：光对不对）   │        │
          │              │        └──► 回到对应的那一步
          ▼              │
   §2 六条画面级判据 ◄───┘
   （第二关：好不好看）
          │
          ▼
      §3 验收清单（只用肉眼）
```

⛔⛔ **过了第一关不会自动过第二关。**
实证：一组十张里，有三张的边光、贴身光源、补色对**全部成立**（第一关全过），
交出去一张没留下 —— 差的全在第二关。
六轮迭代里，**有三轮是"光完全正确但整组被毙"**。第二关不是锦上添花，是另一半工作量。

⭐ 如果只记一件事：**别写「唯美的逆光」，去写「太阳低低地卡在她身后两栋楼之间的缝里、和她的头一样高」。**
其余所有规矩都是这一句的推论。

## 1. 第一关：七步装配（解决「光对不对」）

顺序不能换。

### 第 1 步：选构图族 → 这一步决定后面所有写法

先问**这张图要给人看什么**：

| 要看的是 | 族 | 画幅 |
|---|---|---|
| 脸和情绪 | **特写** | ⛔ 只能竖幅 |
| 人，背景只是氛围 | **近景 / 半身** | 竖幅横幅都行 |
| 人**和**这个地方 | **环境人像** | ⛔ 只能横幅 |

⛔ **画幅已经定死时反向约束族**：16:9 里做不出特写（§7.1 有 12 张实证）。
画幅和族冲突 → **改画幅**，不要改措辞。

**产出：相机句。**

- 特写：`她的头和肩膀几乎填满整个画面：额头顶到画框上沿，下巴落在画面正中，两边脸颊快要碰到画框左右两边。`
- 近景：`她在画面右边三分之一处、从胸口往上入镜，脸占画面高度的三分之一，左边三分之二让给背景。`
- 半身：`她在画面右边三分之一处、从腰往上入镜，左边三分之二让给背景。`
- 环境人像：`一张 16:9 横幅的真实照片。她站在画面右边三分之一处、从膝盖往上入镜，身高占满画面高度的四分之三，左边三分之二整个让给风景。`

⛔ **同时决定写到哪个部位为止**（写了哪个部位就等于把画框拉到哪个部位，§8②）：
特写写到**领口**、近景写**上装**、半身写**上装**、中景写**下装 + 腿**、全身写**鞋 + 地面**。

### 第 2 步：定光位 —— 这张要打脸光，还是要镶边光？

⛔ **这一问必须先答。答错了，后面每一步都做对也是废片。**
实证：一组十张里八张的光**在光学上完全正确**（边光、贴身光源、补色全成立），
但主光全在人的**后方** —— 脸只剩均匀的环境光，没有立体感也没有光泽，**人就不美**，八张全毙。

| 你要的 | 主光位置 | 脸上会是 |
|---|---|---|
| 轮廓光 / 发丝光 / 剪影感 | 正后方 / 侧后方 | ⚠️ 只有环境光 —— **必须另外补一个能照到脸的光源**，否则人不美 |
| 打脸光（**人物要美就选这个**）| 侧前方 45° / 正前偏下 / 远处的正前方 | 一块**明确的亮面** + 一块暗面 |

⛔⛔ **不要写「光源在她正前方、和她的脸一样高」** —— 那个位置正好是**镜头的位置**。
模型不肯让光源挡住镜头，一律把它挪到人身后或头顶去（→ §4 那条定律的第 4 个实例）。

⭐ **三种真能打到脸的写法**（都验过）：

| 写法 | 为什么成立 | 例子 |
|---|---|---|
| **侧前方 45°**（伦勃朗）| 光源在画框边缘，不挡镜头 | `一道光从她左前方的老木格窗照进来，正好斜劈在她的半张脸上` |
| **正前偏下** | 光源比脸低，不挡镜头 | `一排暖橘色灯泡挂在她正前方、比她的脸略低一点、直直地照着她` |
| **远处的正前方**（只有太阳能用）| 太阳远到不占画面空间 | `太阳低低地贴在海面上、正好在她的正前方、和她的脸一样高` |

⭐ 打脸光要**把亮面和暗面都写出来**。写「柔和地照亮她的脸」= 均匀光 = 等于没打：
```
把她的额头、颧骨和鼻梁照得发亮，鼻子侧面下方留下一小块三角形的亮斑，
另外半张脸整个落在柔和的暗部里；睫毛在被照亮那半边的脸颊上投下细影
```
⭐ 再补一句**眼睛里的反光点**（`眼睛里有一颗清楚的暖金色反光点`），脸立刻"活"。

### 第 3 步：选光源，并钉死三个维度

**先问「这个场景在这个时刻，什么东西是亮的」：**

| 场景 | 主光源 |
|---|---|
| 日出 / 日落户外 | 太阳（低角度，天然落在头肩高度，最省事）|
| 正午户外 | ⚠️ 没有低位光源 → 改时间，或退回第 1 步换族 |
| 夜晚有人造光（街 / 舞台 / 庭院）| 场景自带的：霓虹 / 灯笼 / 灯箱 / 火盆 / 射灯 / 自动贩卖机 |
| 夜晚无人造光（山顶 / 荒野 / 湖边）| ⛔ 必须自带一个：营灯 / 提灯 / 篝火 / 她手里的发光物（→ §7.4）|
| 室内 | 窗 / 门缝 / 矮处的灯具 |

**再钉三个维度，缺一个就飘：**

**① 距离** —— 判据：**光源离她能不能到半米~两米**。
「整片城市霓虹就在她身后」（几百米外）= 零轮廓光，出来是好看的背景板。
到不了这个距离 → **换光源**，别改措辞。

**② 方位** —— 高度和方位要**一起写**：
`太阳正好在她的头的正后方、从两根松枝之间跳出来、和她的头一样高、正对着镜头`
只写「和她的头一样高」，太阳会飘到侧后方去。
⚠️ **深色主体是例外**，判据见 §6.1。

**③ 支架** —— 光源要架到头肩高度，靠场景里一个东西托住。

⛔ **判据是三条，缺一条等于没有支架：有一道缝 / 比她高 / 离她两米内。**

| 场景类型 | 支架 |
|---|---|
| 自然 | 两棵树干之间 / 一棵孤树分开的两根主枝之间 / 岩石 / 断墙 |
| 城市 | 两栋楼的缝 / 巷口 / 门洞 / 桥洞 / 棚架立柱 |
| 室内 | 门框 / 两扇障子门之间 / 书架之间的窄缝 |
| 人造 | 花架立柱 / 鸟居 / 晾晒的床单之间 / 风车叶板之间 / 舞台桁架 |

- **有缝** —— 没有缝的三种直接换地点：开阔天空、光秃秃的海平线、身后一整面墙 / 一扇门 / 一排橱窗。
- ⛔ **比她高** —— 齐胸高的花穗、芦苇、麦浪**不是支架**（旧版本文写过，2 张实证推翻）。
  ⭐ 原因：**开阔地里太阳的高度由地平线决定**，形容词压不过地平线，齐腰的东西托不住它，
  太阳只会落在人的胯部或干脆掉到地平线下。要抬到头肩高度，必须给一个
  **比她高、并且在画面里画出来的实体**（树 / 花架 / 建筑 / 风车）。
- ⛔ **离她两米内** —— 「太阳卡在她身后两座石雕之间」，石雕在几十米外 → 太阳没进画、
  人身上一条边光都没有。有了支架也不能免掉「距离」那一维。

⚠️ 这一步还有三个坑（灯具名词的高度 / 量词 / 时间词），它们是**同一条定律**的实例 → §4。

### 第 4 步：写场景句 —— 光是靠场景写出来的，不是靠形容词

全流程最贵的一条。**把场景写成物理上只可能这么打光**，而不是形容光。

`场景句 = 时间地点 + 光源在哪（第 3 步的三个维度）+ 背景被照透 + 天空长什么样`

```
黄昏的老街，一盏很大的红灯笼就挂在她正后方半米、与她的头同高、正对着镜头，
右边三分之二是向远处收进去的整条青石板老街，木格窗被照成发亮的暖橙色，
天空是刚暗下来的深蓝色
```

三条硬要求：

- ⛔ 背景写**「被这个光源从背后照透成发亮的暖金色」**；
  ⛔ **不能写「身后是逆着光的树丛」** —— 会被画成实体暗块，一个光斑都不出。
- ⛔ **时间词不交代天空长什么样**。只写「日出的白花田」出来是大白天。
  要把天空画出来：`太阳只露出一半、天边是浓的橘红色、天顶还是没褪干净的深蓝色`。
- **背景的详略跟着族走**：特写 / 近景写死「糊成一片没有细节」；
  环境人像**反过来要有细节**，并且收尾句里的「浅景深」要摘掉。

### 第 5 步：加一句空气介质

没有介质，光就只是背景亮，不成氛围（实测暖冷分离 −10.11 → +1.37）。
跟着场景选：尘埃 / 飞絮 / 花瓣 / 水雾 / 雪粒 / 火星 / 干冰烟 / 细雨丝 / 晨雾。

```
空气里浮着被照亮的细尘
```

### 第 6 步：写光落在哪 —— 逐条点名，别只说「有轮廓光」

**能透光的主体**（浅色头发 / 薄纱 / 飞起来的碎发）：
```
她外圈飞起来的碎发被这道光一根一根照透、亮成细细的暖橘色亮线，
肩线和手臂外缘都镶着一条暖金色的亮边
```

**深色主体**（判据见 §6.1）：光源偏一侧，把亮线**逐条点名落在哪几条边**：
```
把她银白色头发的外圈、右边肩膀的边缘和右臂的外侧各照出一条清晰的暖金色亮线
```

**特写族**额外加一句（这是"好看"的开关，不是修辞）：
```
脸的其余部分落在柔和的暗部里
```

⛔ **光斑落点要正向限定**：`金色光斑全部落在她身后很远的虚化背景里` ——
不限定它会飘到脸上变成一颗橘色圆饼。

### 第 7 步：配第二色温 —— 补色对

**光已经对了但画面还是平，九成是因为整张图只有一个色温。**

| 主光是暖的 | 冷的那一半去哪找 |
|---|---|
| 暖金落日 / 日出 | 天顶还没褪的深蓝、远山的冷蓝剪影、雾蓝色的衣服 |
| 暖橘灯（灯笼 / 钠灯 / 马灯 / 橱窗灯箱）| 刚暗下来的暮蓝天、冷蓝的雪夜、深青蓝的街 |
| 火橘 / 熔岩 | 深蓝紫的夜空、远处冷灰的山影 |

| 主光是冷的 | 暖的那一半去哪找 |
|---|---|
| 青蓝霓虹 / 自动贩卖机 | 侧后方一块暖橘灯牌、暖橘的窗灯、拉面店暖帘 |
| 蓝紫射灯 | 台下一片暖橘荧光棒、侧面补一盏暖橘灯 |
| 冷蓝银河 / 月光 | 身边一盏暖黄营灯、地平线上一线没褪的暖橘暮色 |

一句话记法：**主光暖的，去天空和远景找冷的；主光冷的，在近处塞一个暖光源。**

### 装配

按 `相机句 → 人物 → 姿态神态 → 场景光源句 → 介质 → 光落在哪 → 补色 → 收尾` 拼起来。
收尾句：`真实照片，浅景深。画面里只有她一个人，双手五指完整，没有文字水印。`
（环境人像去掉「浅景深」。）

## 2. 第二关：六条画面级判据（解决「好不好看」）

⛔ **§1 只保证「光没错」。这六条决定「好不好看」，是独立的一关。**
它们不是从光学推出来的，是把**被选中的**和**被毙的**成品并排比出来的。

⭐ **⑥ 是目前唯一一条能 100% 分开"选中"和"被毙"的判据，先查它。**

### ⑥ 背景要「少而大」，并且带一条干净的几何线

| | 被选中的 | 被毙的 |
|---|---|---|
| 背景 | 海+天 / 一整面暗墙 / 暮蓝天 / 雪街 —— **元素少、块面大** | 夜市摊档 / 宴会厅一堆糊光斑 / 观众席人头 / 一片碎树干 |
| 几何线 | 窗棂格 / 海面反光带 / 木马顶棚弧线 / 花架长廊 / 桥架透视 / 梯田曲线 | **一条都没有** |

⛔ **细碎堆叠的背景，虚化解决不了。** 摊档、人群、一堆散落的光斑，糊了照样把画面搅浑
—— 它们提供的是"信息量"不是"结构"。

⭐ 两条修法，二选一或都要：
- 给一条**贯穿画面的线**：透视走廊（花架 / 鸟居 / 樱花隧道 / 桥架 / 街道 / 车厢）、
  水面反光带、梯田曲线、栏杆、窗棂、一排灯、山脊、地平线。
- 把背景**换成一两块大东西**：海 + 天 / 雪坡 + 天 / 一整面墙 / 一整片暮色。

⭐⭐ **两条出片率最高的配方，优先试：**

| 配方 | 为什么强 |
|---|---|
| **太阳盘 + 水面（冰面 / 湿路面）反光带** | 反光带本身就是一条**从光源直指人**的引导线，一次同时满足⑤和⑥，还自动带上①和② |
| **长廊 / 隧道尽头的光源** | 透视线把视线送到光源上，再送回人身上（紫藤花架、樱花隧道、千本鸟居、地下通道）|

### ⑤ 光源实体要入画

太阳盘 / 一排灯泡 / 一扇窗 / 一堆篝火 / 一盏灯笼 / 一块橱窗灯箱 —— **把那个东西本身画出来**，
让人看得见光是从哪来的。
⚠️ 和①不是一回事：①要的是「被照的一大片东西在发光」，⑤要的是「光源本体在画面里」。

### ① 要有一大片「被主光照透、自己变成光源」的介质，占画幅 ≥ 1/3

光只落在人身上不够。判据是**这片东西自己在不在发光**。两种常见的假货：

| ⛔ 不算 | 为什么 |
|---|---|
| 松针 / 藤蔓叶 / 砖墙 / 铁架 | 不透光，背光时是实体暗块 |
| 城市霓虹 / 窗灯 / 银河 / 远处的云海 | 亮，但在几百米外，且不可能被"照透" |

可透光清单（都验过）：花穗 / 花瓣 / 落叶 / 芒草穗 / 蒲公英绒毛 / 雪帘 / 雨丝 / 火星 /
水花 / 雾里的光柱 / 薄纱或透明雨衣。
⭐ 一组里让它们**互不重复**，比换场景更能拉开一组图的差异。

### ② 补色对要比面积和饱和度

不是「画面里有两个色温」就算。判据：冷的那一半**占不占得到 1/4 画幅**、是不是饱和色。
一整片饱和紫的花架 ✅；一条淡蓝棉布裙 ❌（整张仍会读成全暖）。

### ③ 画面里必须有一块真正的黑

全是柔灰中间调 = 发闷、不抓眼。
⛔ **黑锚要挂在场景里，不能指望主体的衣服** —— 戏服由角色 / LoRA 决定，不受场景句控制
（写好的黑制服出成白裙，黑锚当场消失）。
挂场景的：树干 / 立柱 / 屋瓦 / 山脊剪影 / 湿黑路面 / 风车木架 / 车厢暗部。

### ④ 服装是画面元素，不是背景板

一组十张里连出四张「奶白针织衫 + 牛仔裤」，光再对也只是随手拍。
判据：一组里**有没有重复穿同一件**；单张看**这身衣服有没有颜色和廓形**。

## 3. 验收清单 —— 只用肉眼，分两组

**第一组（光对不对）：**

1. 发丝 / 轮廓有没有**一根根**亮起来？ —— 没有 → §5 诊断表
2. 画面里有**几个**色温？ —— 只有一个 → 第 7 步
3. 主体够不够大？脸占画幅 < 1/5 → 第 1 步换族

**第二组（好不好看）—— ⛔ 第一组全过也可能这组全废：**

4. **背景是「少而大」还是「细碎堆叠」？找得出一条贯穿画面的线吗？** → §2 ⑥
5. **脸上有没有一块明确的亮面**（分得出亮面和暗面，不是均匀的环境光）？ → §1 第 2 步
6. **光源实体在不在画面里？** → §2 ⑤
7. 有没有**一大片东西自己在发光**？ → §2 ①　冷色够不够大够不够艳？ → §2 ②
8. 有没有**一块真正的黑**？ → §2 ③　这身衣服是不是路人装？ → §2 ④

**一组图还要多一问：十张摆在一起，像不像同一张？**
单张都成立、一组读起来是一张，就是模板化。沿三个轴拉开，缺一个就还是一个味道：
**景别**（近景 / 半身 / 中景轮着来）、**光位**（正前 / 前侧 / 侧后 / 正后 / 自下而上）、
**场地类型**（室内 / 海 / 街 / 雪原 / 山野 / 花树 / 工业…十张不重样）。

⛔ **数值只能证伪不能证真** —— 数值最漂亮那组是「人身上一点光都没有的好看背景板」，
踩过三次。量化指标的用法和五个陷阱见 §9。

⭐ **验收前先抽 3~8 个种子。** 同提示词换种子的摆幅比绝大多数措辞改动都大 ——
成品是从约 300 张候选里挑的，**每个位置都换掉了默认那张**。别拿单张判断措辞好坏。

## 4. ⭐ 一条定律：名词自带的语义，压得过任何形容词

这条不是某个坑，是**五个坑共同的解释**，也是这份文档里唯一能**预测新情况**的东西。

> **模型先按名词的常识把东西放好，再去读你的形容词。
> 形容词只能微调，推不动名词自带的位置 / 高度 / 数量 / 时间 / 属性。**

| 名词带进来的 | 症状 | ⛔ 压不住的写法 | ✅ 解法：换名词 / 换类别 |
|---|---|---|---|
| **高度**（灯具装在哪）| 顶光，脸压平 | 「路灯，灯头和她的头一样高」| 换**本来就矮**的灯具：矮墙上的马灯 / 台灯 / 灯笼 / 帐篷杆上的营灯 |
| **高度**（招牌装在楼上）| 光源被画到二楼外墙 | 「霓虹灯箱招牌，比她高出一头」| 换**天生齐人高的面光源**：自动贩卖机 / 橱窗灯箱 |
| **数量与排布**（量词）| 光源跑到两侧，边光全没 | 「一**串**红灯笼挂在她身后」| 用**单数**；单数还不够就**给画面里的尺寸**（「占画面高度的四分之一」）|
| **镜头位置**（正前齐脸高）| 光源被挪到身后 / 头顶 | 「一排灯泡在她正前方、和她的脸一样高」| 挪开镜头位：**侧前 45°** / **正前偏下** / **远处的太阳** |
| **时间里有没有太阳**| 太阳没进画，只剩余晖天 | 「**黄昏**的蒲公英坡」| 写「**日落 / 日出**」+ 明写实体：`太阳还没落下去、是一个明晃晃的圆盘` |
| **因果被当成妆容**| 两坨腮红 | 「脸颊被冻得有点红」| 别写「因为 X 所以 Y」，改写**皮肤本身的质地** |

⭐ **怎么用它预测新坑**：写完一句先问自己——
**这句话里的名词，本身带不带位置 / 高度 / 数量 / 时间 / 状态的常识？**
带，而我要的正好和它相反 → **现在就换名词，别指望形容词**。
⛔ 反面教材：为了把太阳拽到头高，我在同一个方向连改四版（换支架三次），
最后发现卡的是「黄昏」两个字 —— 改成「日落」一次就出来了。

## 6. 三个决策点的判据

### 6.1 深色主体判定 → 光源钉正后方还是偏一侧

**判据：主体朝向镜头的那一面，有没有能透光的东西**（浅色头发 / 薄纱 / 飞起来的碎发 / 浅色衣服）。

- **有** → 光源钉**正后方**，写「照透」。碎发、纱、浅色发会一根根亮起来。
- **没有**（深色发 + 深色衣，或整身黑）→ 光源**偏一侧**，写「擦边」，
  并且**逐条点名**亮线落在哪几条边。钉正后方会被身体整个挡住，出来是剪影。

⚠️ 混合情况（银白头发 + 全黑裙）按**深色**处理：偏一侧 + 逐条点名，头发照样会透。

### 6.2 调不动时：先动构图，还是换概念？

- **改光线句 1~2 次没效果** → 先**动构图**（人的位置 / 景别 / 画幅）。
  ⭐ 构图比光更强：同一套光，人从正脸满框挪到侧脸偏一侧，两项指标一次对上参考片。
- **构图也动了，同一个方向改到第 3 版还没动** → **换概念**（换场景 / 换载体 / 换画幅 / 换角色）。
  卡的是结构性的东西，继续磨措辞是纯浪费。
  ⚠️ 换概念前先过一遍 §4：有时卡的只是一个名词（改「黄昏」为「日落」）。

### 6.3 想要一个禁止项（cfg=1 时）

⛔ 负向提示词形同虚设 → 一律**正向化写成肯定句**，把你要的形状正面描述死。
`没有X` 是在召唤 X。对照表见 §8①。

## 7. 附录 A：各族与各档的写法细则

### 7.1 特写族

三件套：① 相机句写死画框（第 1 步）；② 一个**贴脸**的光源（身后一点点的钠灯 / 头顶的伞面 /
她手里的发光小物件）；③ 正向补一句「脸的其余部分落在柔和的暗部里」。

⭐ 第三条是"好看"的开关，不是修辞。明亮的正面光会把脸的所有缺陷平铺出来；
被暗部托着、只有轮廓和高光是亮的，同一张脸立刻上一个台阶。

⛔ **特写只能用竖幅**（实证）：同一句特写相机放进 16:9，连改三版
（放大相机句 → 上装只写领口 → 把光压到日落后）**十二张出图景别一寸没动**、脸始终只占 1/5；
换成竖幅一次到位。16:9 的画框本身在要求横向填充，人只占半边时模型会把另一半补成环境。

### 7.2 近景 / 半身族

光的写法二选一，都验过 6/6：

- **侧脸发丝**：`光从她耳后斜穿过头发，把外圈那些飞起来的碎发一根一根照透、亮成细细的暖橘色亮线，脸颊外缘留下一条细亮边。`
- **正脸环光**：`光源在她正后方、和她的头一样高，整个头的外圈镶上一整圈细细的暖橘色发丝亮线，两边脸颊外缘各留下一条细亮边。`
  ⭐ 正脸一样能有整圈发丝光，不用非把脸侧过去。

背景是流动的虚化色块 + 一句介质。⭐ 颜色不限：绿 / 粉 / 金 / 霓虹 / 冷白全成立，别一律刷暖金。

### 7.3 环境人像族

⛔ 最容易退化成「风景很美、人身上一点光都没有」的好看背景板。
防线只有一条：**风景可以铺满，但主光源必须留在她身边**。
远处的城市灯火、云海、山谷灯火**只能当第二层**（补色的那一半），不能当主光。

⚠️ 这一族**过了防线也常常只是"不废"**，离"好看"还差整个 §2 —— 横幅里人天然小，
撑场面的必须是那片会发光的介质和那条几何线，不能只靠人身上一圈边光。
⭐ 这一族的介质**吃画幅**：特写里够用的萤火虫 / 细尘，放进横幅就撑不起 2/3 的风景
（→ §7.4），要换成整片的花穗 / 落叶 / 雪 / 火星 / 水花 / 光柱。

### 7.4 自发光档（唯一的冷调路子）

⛔ 和逆光**方向相反**，不是它的一个场景。三条内核：
① 全图唯一的主光是她手里 / 身边那个**自己会发光的小东西**；
② 人整个压在暗部，脸比那个光源暗好几档；
③ 冷调低饱和，**全画面只有那个光源是另一个颜色**。

- ⛔ **改暖调直接废**（冷是命根子）；⛔ **去掉那个发光物直接废**（它是唯一主光）。
- ⭐ 内核和道具无关，**换载体照样成立**：粉百合 → 掌心萤火虫 → 帐篷杆上的营灯 → 篝火，
  三条一条没改，画面完全是新的。**先拆这三条再挑载体，别照抄道具。**
- ⚠️ **载体亮度要配得上画幅**：萤火虫在特写里够用，放进横幅环境人像里光量撑不起
  2/3 的风景，整张发闷发空 —— 换营灯 / 提灯 / 篝火。

## 8. 附录 B：⚠️ 模型相关 —— 换模型要重新验

**① cfg=1 时负向提示词形同虚设。**
适用于所有开了 Lightning / turbo / 蒸馏加速的模型。填了不报错，只是不生效。

| 想要 | ⛔ 写不出来 | ✅ 正着写 |
|---|---|---|
| 不要投影 | negative: `shadow` | 「每个物体都直接贴在白纸上，不产生任何投影」 |
| 脸别太圆 | 「脸不胖」 | 「窄长的鹅蛋小脸，脸颊平顺内收、下颌角收窄，下巴是尖的」 |
| 皮肤干净 | 「无瑕 / 没有痘」 | 「脸颊、下巴和嘴角是连续平整的一片皮肤」 |
| 短裙别变连体衣 | 「不是连体衣」 | 「裙筒是完整闭合的一圈、四周一样齐地把大腿包住」 |
| 丝袜不透明 | 「不透明的丝袜」 | 换名词：「天鹅绒打底裤袜」 |

规律叫「**可选结构改成不可选**」。⚠️ cfg 提到 4 以上负向才真正生效，代价是步数和时间。
⚠️ 注意区分：这条是**负向框不生效**；§4 那条是**正向里名词压过形容词**。两条都要守。

**② 字数预算是控景别的主变量，比相机句强。**
⭐ **景别靠画框内的身体 / 服装内容撑出来** —— 写了哪个部位，就等于把画框拉到哪个部位。
实测：中景写「裙摆垂到小腿」画框滑成全身；特写写「她穿着开衫」立刻退回胸像。
⚠️ 字数区间是模型相关的（这套 z-image + LoRA：近景 405~448 / 中景 468~510），
换模型要重新标定；**但「长度是主变量」这条通用**。
⭐ **还原度优先于字数上限**：削长度时从戏服末尾砍分句，砍掉的正好是还原度最吃重的名词
（盘扣、腰带流苏、白长手套、羽毛状裁片）。横幅实测 475~656 字景别全正常 ——
上限该重标就重标，别让它吃掉戏服。

**③ 景别没守住时，画框外的字段会被模型自己编出来。**
⭐ 修法**不是加字数，是换景别**：改走本来就要写那个部位的景别，再用肯定句写死它。

**④ 同提示词同 seed 未必可复现**（这套 ComfyUI 下平均像素差 29/255）。
任何改法先过噪声底，别把噪声当成措辞的效果。

**⑤ 同一个人在同一组里，脸的那句必须一字不差地复用。** 做成同一个字符串常量。

**⑥ 挂角色 LoRA 时，「景别槽」同时决定戏服写多少 —— 别为了脸大就选最近的那档。**
⚠️ 字段名和模板绑定，但**"最近的景别档往往没有完整服装字段"这个坑是通用的**：
这套 cos 模板里近景档走 `基底近 + 领`（**没有上装字段**），戏服还原度直接掉一大截。
⭐ 要「脸大 + 戏服完整」，正解是**半身档**：有完整上装、不写腿 → 画框自然收到腰。

## 9. 附录 C：量化指标 —— ⛔ 只能证伪，不能证真

口径（实现在 `docs/对照实验.md`）：P1 = 最暗 1% 分位亮度；CLIP = 过曝像素占比；
dB = 暖冷分离；HALO = 光晕；LAP = 锐度方差；BGFG = 边缘锐度 / 中心锐度。

⛔ 五条**别当及格线**：

- **CLIP 不是及格线**。曾定过「甜区 0.5~2%」，10 张成品里 8 张 CLIP<0.5、肉眼全部有发丝透光，
  反而超上限那张是唯一光糊掉的。它只能抓「光源盘被拽进画面」那种爆掉的（>3%）。
- **dB 只对有冷环境光的场景有意义**。海边 / 雪原 / 樱花 dB 是负的，画面并不差。
- **HALO 在高光像素太少时直接返回 0**（光源出画必为 0），别读成「没有光晕」。
- **LAP 不能跨场景比**。夜景天然高（雨后夜街 386，白天档 29~110）。
- **P1 不能跨构图族比**。满画面逆光的 P1 天然 20~50，近景那条 P1≈15 套到全身上全是误判。

## 10. 附录 D：实验依据

流程里的每一步都来自一组只改一句话的 A/B，这里是出处，供不信的人复核。

**① 光靠场景写，不靠形容词。** 光线形容词堆句尾、五档强度递进，三项指标**纹丝不动**；
场景句从「身后是干净的暖白色墙面」换成「身后是敞开的店门和门外的街道」，
逆光一次就出来（暗部抬升 7→12、过曝 0.2%→3.8%）。原因：**墙把光源挡在画框外了**。

**② 空气必须有介质。** 只写「金色时刻」暖冷分离 = −10.11；加「空气里浮着被照亮的细小尘埃」→ +1.37。

**③ 不许单独写「暗部是冷的」。** 模型会把整张图一起吹冷（暖冷分离掉到 −1.04）。
暖冷分离只能靠**场景自带两个色温的光源**。

**④ 柔焦类提示词零效果。** 五档柔焦写法实测锐度不降反升（LAP 275→318），肉眼五张无差。
要柔只有两条路：加雾（晨雾把 LAP 96 压到 55），或放后期做 bloom。

**⑤ 构图比光更强。** 同一套光，人从正脸满框挪成侧脸偏一侧，
两项指标一次对上参考片（LAP 96→24.5、BGFG 0.48→3.36）。

**⑥ 补色对是「抓不抓眼球」的直接来源。** 把成品和被淘汰的那批并排比，
最强的信号不是光有多准，是**画面里有没有两个对立的色温**。

**⑦ 光源离主体远 = 零轮廓光。** 「整片城市霓虹就在她身后」（几百米外）出来是背景板；
「太阳卡在她身后两棵树的树干之间」（树太远）同病。

**⑧ 支架必须有缝、比她高、离得近。** 光秃秃的海平线和开阔天空五种措辞出图几乎一模一样；
身后一整面墙 / 门 / 一排橱窗，36 张里 10 张栽在这上面。
齐腰的鼠尾草和齐胸的芒草托不住太阳（2 张实证），换成孤松 / 风车立刻成立。

**⑨ 逆光只镶边不打脸 = 人不美。** 一组十张里八张边光 / 贴身光源 / 补色全成立、
主光全在后方，八张全毙；改成侧前 45°、正前偏下、远处正前方三种打脸光后全部翻身。

**⑩ 背景「碎 vs 大」是选中与被毙之间唯一 100% 分得开的变量。**
选中的背景全是大块 + 一条几何线；被毙的全是细碎堆叠且一条线都没有。

**⑪ 名词自带的语义压过形容词。** 五个独立实例（灯具高度 / 招牌高度 / 量词 / 镜头位 / 时间词），
每个都是"形容词连改数版无效、换名词一次成立"。见 §4。
