# z-image 人像光线配方

> 十五轮 ~120 张**同种子单变量**对照打出来的。每一条结论都对应一组只改一句话的 A/B。
> 四个档的完整可复制提示词在 `docs/配方全文.md`，逐轮归因和数值在 `docs/对照实验.md`，
> 十张成品在 `assets/`。

## 0. 先分档 —— 四个档的规律互相矛盾，混用必废

| | 暖金逆光·全身 | 侧脸发丝·近景 | 正脸环光/斜后光·近景 | 冷雾特写 |
|---|---|---|---|---|
| 长什么样 | 背景照透成暖金，人镶一圈金边 | 侧脸，碎发一根根亮成橘线 | 正脸，整圈或半边发丝亮线 | 冷蓝纱帘 + 手捧发光粉百合，人压暗部 |
| b\* | **正**（≥8） | 正（9~29） | 正 | **负**（≤ −10，参考 −13.5） |
| 靠什么成立 | 场景几何（光源在她身后头肩高度） | 构图（侧脸 + 近景） | 光的**写法**（斜后 / 环） | 手里一个发光小物件 + 厚雾 + 压暗 |
| 配方键 | `配方.全身档` | `配方.侧脸近景档` | `配方.侧脸近景档._r14扩展.正脸` | `配方.冷雾特写档` |

选档口诀：**全身看场景几何，近景看构图和光的写法，冷调只走冷雾档。**

## 1. 五条通用硬结论（这五条是全部成本的来源，别再重验）

**① ⛔ 光是靠场景写出来的，不是靠形容词。** 最贵的一条。
光线描述堆在句尾、五档递进写法，P1/dB/HALO **三项纹丝不动**（r1）；
场景句从「身后是干净的暖白色墙面」换成「身后是敞开的店门和门外的街道」，
逆光一次就出来（r2：P1 7→12、过曝 0.2%→3.8%）。
**场景要写成物理上只能这么打光。**

**② ⛔ 空气里必须有被照亮的东西**（尘 / 絮 / 水雾 / 雪粒 / 花瓣）。
只写「金色时刻」dB = **−10.11**，加一句「空气里浮着被照亮的细小尘埃」→ **+1.37**（r3）。
没有介质，光就只是背景亮，不成氛围。

**③ ⛔ 不许单独写「暗部是冷的」。** 模型不会只冷暗部，它把整张图都吹冷
（r3 N3：b\* 掉到 −1.04；全身档 T2 E 组：dB 1.93→−1.48）。
暖冷分离只能靠**场景自带**（树林的暖光柱 + 冷绿树荫 dB 7.15）。

**④ ⛔ 柔焦提示词零效果，必须放后期。** 五档柔焦写法实测 LAP **275→318**（反而更锐），
肉眼五张无差（r6）。用 `柔光后期.py --档 轻`（只做 bloom）。
⚠️ 唯一有效的提示词侧软化是**加雾**（晨雾把 LAP 96 压到 55）。

**⑤ ⭐ 构图比光更强。** 同一套光，正脸满框 → 侧脸偏一侧：
LAP 96→24.5、BGFG 0.48→3.36，一次对上参考片（16.6 / 3.99）。
模型是听得懂「她站在画面右边三分之一处」的。

## 2. cfg=1 的写法铁律（z-image / Lightning / turbo / S2V 全适用）

**⛔ cfg=1 时负向提示词形同虚设，所有禁止项必须正向化写成肯定句。**
往负向框里填不报错，只是不生效 —— 最容易误判成「模型不听话」。

| 想要 | ⛔ 写不出来 | ✅ 正着写 |
|---|---|---|
| 不要投影 | negative: `shadow` | 「每个物体都直接贴在白纸上，不产生任何投影」 |
| 脸别太圆 | 「脸不胖」 | 「窄长的鹅蛋小脸，脸颊平顺内收、下颌角收窄，下巴是尖的」 |
| 皮肤干净 | 「无瑕 / 没有痘」 | 「脸颊、下巴和嘴角是连续平整的一片皮肤」 |
| 短裙别变连体衣 | 「不是连体衣」 | 「裙筒是完整闭合的一圈、四周一样齐地把大腿包住」 |
| 丝袜不透明 | 「不透明的丝袜」 | 换名词：「天鹅绒打底裤袜」 |

规律叫「**可选结构改成不可选**」：`没有X` 是在召唤 X，
唯一有效的办法是把你要的那个形状**正面描述死**。

## 3. 四个档的具体写法

### 3.1 侧脸发丝档（近景，10 场景 10/10）

三件套，缺一不可：
1. **侧脸或四分之三侧**，人在画面一侧、从胸口往上入镜，另一侧一大片虚化背景。
2. **「光从她耳后斜穿过头发，把外圈那些飞起来的碎发一根一根照透、亮成细细的暖橘色亮线，脸颊外缘留下一条细亮边。」**
3. 背景是流动的虚化色块 + 一句被照亮的空气介质。
   ⭐ 颜色不限：绿 / 粉 / 金 / 霓虹 / 冷白全成立，**别一律刷暖金**。

拼接顺序：`相机 → 脸 → 皮肤 → 发 → 衣 → 神态 → 场景 → 光 → 尾`，总长 ~350 字。

⛔ **句尾不接「阳光直接照进镜头」** —— 那句会把太阳盘拽进画面，CLIP 冲到 3.5%（60 张废在这上面）。

### 3.2 正脸档（r14 推翻旧结论）

⭐ **正脸也能保住发丝光**，早先「正脸满框会把光锁死成硬边缘光」是错的。
关键是换**光的写法**，两种都 6/6：

- **斜后光**（最像自然光，只亮半边）：
  「光从她左后方斜着打过来，只照亮左半边的头发和左脸颊的外缘，把左边那些飞起来的碎发一根一根照透、亮成细细的暖橘色亮线，右半边留在柔和的暗部里。」
- **环光**（正脸最稳，整圈亮线）：
  「光源在她正后方、和她的头一样高，整片背景被从背后照透成发亮的暖金色，她整个头的外圈镶上一整圈细细的暖橘色发丝亮线，两边脸颊外缘各留下一条细亮边。」

配套两条：
- ⭐ **笑能开到大笑** 4/4（抿嘴 / 微笑露上排牙 / 甜笑眯月牙 / 侧头大笑），不崩脸也不顶掉光。
  ⚠️ 只在**不挂 LoRA** 时成立 —— jpstreet_v3 之类把中性表情烤进权重了，关键帧笑不出来，交给视频模型去笑。
- ⭐ **多人成立** 4/4，人数全准。⛔ **两处必须一起改，漏一处塌回一个人**：
  收尾句「画面里只有她一个人」→「正好两个人 / 三个人」；场景句「她身后」→「她们身后」。

### 3.3 全身档（竖幅 832×1216，⛔ 规律和近景完全不同）

近景靠「背景整个化成光斑」，全身档背景是实景，只能靠**场景几何**：

1. **光源在她正后方的头肩高度**，靠「她身后有高的东西」架起来：树干 / 楼缝 / 巷口 / 门洞 / 灯杆 / 棚架立柱。
   ⛔ **光秃秃的海平线和开阔天空写什么都没用** —— 五种措辞出图几乎一模一样，太阳雷打不动钉在地平线上。
2. 「整片背景被这个光源**从背后照透成发亮的暖金色**」。
   ⛔ 写「身后是逆着光的树丛」会被画成实体暗块，一个光斑都不出（b\*=2.5）。
3. 空气有介质。
4. 光斑落点**正向限定**：「金色光斑全部落在她身后很远的虚化背景里」——
   不限定它会飘到脸上变成一颗橘色圆饼。
5. 夜景照做，把太阳换成**她身后头肩高度**的暖黄路灯 / 壁灯 / 霓虹 / 灯箱，四条一字不改。

⛔ **身后不能有一整面墙 / 一扇门 / 一排橱窗**（36 张里 10 张栽这上面）——
墙把太阳挡在画框外，模型改从正面补光，全退化成平光。
修法：站到**巷口 / 门洞 / 两根柱子之间的缺口正中**，10 张修好 8 张；
剩下那种「场景全部内容就是一整面平面」的**直接换地点**，别硬凑。

### 3.4 冷雾特写档（ref3 那条路）

⛔ 和暖金逆光**方向相反**，不是它的一个场景。
① 正脸大特写，只有头和肩膀入镜；
② 背景是一整面被照透的白色薄纱窗帘、糊成一片、**比她的脸还亮**（人压在暗部）；
③ 她双手捧一朵粉百合举到嘴边，**花心里像点着一盏灯**，是全图最亮的东西；
④ 厚雾；⑤ 压暗；⑥「全画面只有那朵花是粉色的」；⑦ **黑色长直发**（浅棕卷发在这档不成立）。

- ⛔ **改暖调直接废**：冷是命根子，不是风格偏好。
- ⛔ **去掉花直接废**：花是这一档唯一的主光。
- 定稿全文在 `docs/配方全文.md` 的「冷雾特写档」，直接抄。

⭐ **这一档的内核和「百合 / 纱帘」无关，换载体照样成立**：
① 全图唯一的主光是她手里那个**自己会发光的小东西**；② 人整个压在暗部，脸比光源暗一档；
③ 冷调低饱和，全画面只有那个光源是另一个颜色。
把百合换成**掌心里的萤火虫**（黄绿光从指缝漏出来照亮下巴鼻尖），三条一条不改，画面完全是新的
（`assets/04-fireflies-in-hands.jpg`）。用这一档时**先拆出这三条再挑载体**，别照抄花。

## 4. 量化验收 —— ⛔ 五条**别当及格线**

度量口径（`docs/对照实验.md` 里有实现）：P1 = 最暗 1% 分位 L；CLIP = L>250 像素占比；
dB = b\* 最亮 15% 减最暗 25%；HALO = L>235 核心周围的环；LAP = 中心拉普拉斯方差；
BGFG = 边缘锐度 / 中心锐度）。

| | P1 | dB | b\* | HALO | LAP |
|---|---|---|---|---|---|
| 参考片 28 帧 | 15.5 | 8.44 | 13.19 | 1.66 | 19.4 |
| 改造前写真 20 张 | 8.0 | 1.43 | 8.13 | 1.33 | 221 |
| 定稿 r10 树林 | 20.0 | 6.12 | 12.15 | 1.75 | 58 |

- ⛔ **CLIP 不是及格线**。曾定过「甜区 0.5~2%」，10 张成品里 8 张 CLIP<0.5、肉眼全部有发丝透光，
  反而超上限那张是唯一光糊掉的。它只能抓「太阳盘被拽进画面」那种爆掉的（>3%）。
- ⛔ **dB 只对有冷环境光的场景有意义**。海边 / 雪原 / 樱花 dB 是负的，画面并不差。
- ⛔ **HALO 在 L>235 像素少于 50 个时直接返回 0**（光源出画必为 0），别读成「没有光晕」。
- ⛔ **LAP 不能跨场景比**。夜景天然高（雨后夜街 386，白天档 29~110）——
  暗背景 + 高光发丝本来就是高方差。
- ⛔ **P1 不能跨档比**。满画面逆光的 P1 天然 20~50，参考片自己的逆光帧也是 36~41；
  近景档那条 P1≈15 套到全身档上全是误判。

⚠️ **数值全对也可能是废片** —— 数值最漂亮那组人身上一点光都没有，就是个好看的背景板。
这条踩过三次。**唯一可靠的验收是肉眼看发丝有没有一根根亮起来。**
⛔ 同提示词同 seed 在这套 ComfyUI 下**不可复现**（平均像素差 29/255），任何改法先过噪声底。

## 5. 落到生产线上的三条工程规矩

**⛔ 字数预算是控景别的主变量，比相机句强。**
r14 实测「半身 0/2 —— 相机句喊『从腰往上入镜』没用」：
**景别是靠画框内的身体/服装内容撑出来的**。所以两件事同时做：
① 按景别选字段（近景写领口、半身写上装、中景写下装+腿、全身写鞋+地面）；
② 卡字数（cos 定档：近景 405~448 / 半身 477~510 / 中景 468~510 / 全身 480~523）。
全身档 810~891 字时 0/3 收不进鞋和地面，压到 ~500 字后 15/15 全收进去 —— **就是长度**。

**⛔ 「删掉画框外的描述」必须先按「；」分段、再在段内按「，」筛，不能两级各扫一遍全文。**
两级各扫一遍时，一个 `；` 分句只要末尾带一个框外词，整条（含**唯一的颜色锚点**）会被一起删掉，
模型没颜色可依就自己编 —— 实测「黄色缎面抹胸长裙，…，裙身侧面一道到大腿根的高开叉」在半身档
被整条删光，只剩「宽檐草编帽」，缎面被渲染成米色/香槟色。
嵌套筛之后坏的只删到子句一级，颜色和材质留在画框内那一半。

**⭐ 同一个人在同一组里，脸的那句必须一字不差地复用。**
近景/半身/中景/全身各写一句「差不多的脸」= 跨景别长相飘。
把 `基底近` 和 `基底` 的脸句做成同一个字符串常量，跨组之间可以不同。

**⛔ 光源离主体远 = 零轮廓光，措辞再对也救不回来。**
「夜晚天台的边缘，整片城市霓虹就在她身后」——霓虹在几百米外，落到人身上的光约等于零，
模型改从正面补光，出来是**好看的背景板**。同一条也砸过「太阳卡在她身后两棵树的树干之间」
（树太远）。⭐ 判据换成**光源离她有多近**：齐腰的花枝之间 / 身后与肩同高的火盆 /
架在身后与头同高的射灯 —— 这三种一次就对。舞台是所有夜场里最好写的，
射灯位置和干冰烟两条硬要求场景自带。

**⛔ 景别没守住时，画框外的字段会被模型自己编出来。**
半身档按规矩不写下装（在画框外），前提是画框真的切在腰上；提示词一长画框滑到膝盖，
下半身进了画面而提示词里一个字都没有，模型就自由发挥 —— 编出来的通常又不还原又难看。
⭐ 修法**不是加字数，是换景别**：改走中景（中景本来就要写下装），
再用肯定句把它写死（「裙筒是完整闭合的一圈、四周一样齐地把大腿包住」）。

## 6. 挑片比改措辞收敛快

⭐ **同提示词换种子的摆幅，比绝大多数措辞改动都大。**
同一条在这套 ComfyUI 下同 seed 都不可复现（平均像素差 29/255），
所以任何改法先过噪声底；反过来，**一次抽 3 张挑最好的，比反复改提示词有效得多**。
这十张成品是 30 张候选里挑出来的，10 个位置全部换掉了默认那张。
